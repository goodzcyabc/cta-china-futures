## 2. 字段说明

| 字段 | 含义 |
|---|---|
| announce_date | 公告发布日(公告页"发布日期")。派生记录(notes 以 `DERIVED` 开头):CZCE 为空;SHFE/INE 为 notes 中链接到的最近相关公告的发布日,链接不到则为空 |
| effective_date | 生效日,按公告原文口径:"X 月 X 日收盘结算时起"取 X 月 X 日(保证金当日结算起生效,涨跌停自下一交易日起);"自 X 月 X 日起"取 X 月 X 日;节后恢复条款取恢复交易首日,notes 注明"以第一个未出现涨跌停板的交易日结算时起恢复"的条件;派生记录为参数文件日期(保证金/手续费 = 该日结算起适用;涨跌停 = 该日交易时段已适用) |
| exchange | SHFE / INE / CZCE(DCE 未覆盖) |
| symbol | 大写品种代码(CU、MA、SC…) |
| contract_scope | `all`=该品种全部合约;具体合约 `BU1606`、区间 `CU2607-CU2702`、列举 `RB1701,RB1705`;原文为描述性范围时照抄原文 |
| param | margin(一般/投机持仓交易保证金比例;套保比例见 notes)、limit(涨跌停板幅度)、fee(开仓/非平今交易手续费)、fee_close_today(平今仓手续费)、position_limit(持仓限额)、other(交易限额=日内开仓最大数量等,notes 说明) |
| direction | up / down / restore;按参数数值方向(交易限额、持仓限额"下调=收紧");公告写"恢复"为 restore |
| old_value | 原值。公告原文写出的("由 8% 调整为 9%")直接取;原文未写时由交易所日参数文件回填(前一交易日),notes 注明 `old_value from param file` |
| new_value | 新值。保证金/涨跌停为小数(0.09 = 9%);手续费按 unit;"恢复至原有水平"未写数值时由参数文件回填(notes 注明 `new_value from param file`) |
| unit | ratio(小数比例)、bp(成交金额的万分之几,万分之0.5 = 0.5)、CNY_per_lot(元/手)、lots(手)、pct_of_open_fee(平今费为开仓费的百分比) |
| reason | holiday / volatility / restore / temporary / new_contract / rule / other / none,多值用 `;`。派生记录中 `rule` = 规则自动扩板而非公告:CZCE 取参数文件"是否单边市"列(该日或前一日有合约为 Y);SHFE/INE 取"5 天内 A→B→A 原路回退且无公告行"的启发式 |
| notice_id | 文号(上期发〔2026〕249号、上能发〔2026〕103号…);派生记录为空 |
| url | 一手来源:SHFE 公告页;INE 公告取上期所官网转发页(正文含上能发文号与全文,ine.cn 原页被 WAF 拦截);派生记录为当日参数文件(CZCE `FutureDataClearParams.txt`;SHFE/INE `Settlement<日期>.dat` / `ContractDailyTradeArgument<日期>.dat`) |
| notes | 套保比例、条件、原文片段、`PARAMCHECK=match/mismatch(...)` 参数文件校验结果、`old_value/new_value from param file` 回填标记、`direction confirmed/corrected` 方向判定、`REVIEW:` 抽取员标注的不确定项、`DERIVED` 派生记录说明(众数覆盖合约数、前一文件、变动合约数、最近公告链接) |

## 3. 抽取方法

生成会话 scratchpad:`/private/tmp/claude-501/-Users-mac-code/37d31ef4-eec3-4c89-8b28-5b42e981eb4d/scratchpad/exch/`(脚本、公告文本、参数文件、中间 CSV 都在这里;不进 git)。流水线:

1. **公告发现(SHFE/INE)**:上期所站内搜索 API(`shfe_search2.py`,`https://www.shfe.com.cn/api/search/`,关键词 保证金/涨跌停/手续费/限额/持仓限额/交易限额/平今/日内/风控/调整/恢复,chnldesc=publicnotice)得到 3533 个去重公告 URL(`shfe_search_all.json`);按标题过滤出 1059 份"风控参数类"公告(`shfe_relevant.json`:保证金/涨跌停/手续费/限额/节假日工作安排/风险控制/限制开仓)。能源中心公告在上期所站内以 ine.cn 原链接出现(WAF 拦截、curl 得 404/防火墙页),改用上期所官网的转发页"上海国际能源交易中心发布关于……"(`ine_list.py` 抓 ine.cn 列表 → `ine_match.json` 按日期+标题匹配 153 份,其中 151 份进入抽取;60 份无转发页,见"已知遗漏")。
2. **正文获取**:`shfe_fetch.py` curl 公告页 → 去标签纯文本 `shfe_txt/<id>.txt`(头 3 行 URL/DATE/TITLE);654 份成功,405 份 404(绝大部分是 ine.cn 原链接或"限制开仓监管措施"页,前者已由转发页覆盖)。去掉"限制开仓监管措施"(针对具体账户,无品种参数)与规则修订/存管银行等 189 份后,465 份进入抽取批次 A–G(2016–2017、2018–2019、2020–2021、2022–2023、2024、2025、2026 三段)。
3. **LLM 结构化抽取**:每批一个 Claude Opus 子任务,只读本地文本、不联网,按 `CONVENTIONS.md`(一行 = 一份公告对一个品种的一项参数调整;品种×参数×合约档展开;单位/方向/理由取值表;不确定处 notes 写 `REVIEW:`)输出 `rows_<批>.csv`、`skipped_<批>.txt`(不产出行的公告及原因)、`review_<批>.txt`。`batch_qa.py` 校验每份公告都在 rows 或 skipped 中出现:

4. **合并与规范化**(`merge.py`):列名/日期/数值/文号格式统一,同一(文号,品种,合约范围,参数,生效日,新值)去重。
5. **参数文件校验与回填**(`verify.py`):对每一 SHFE/INE 公告行,读交易所日参数文件(Settlement / ContractDailyTradeArgument `.dat`,SHFE 文件同时含 INE 品种且与 INE 自身文件逐合约一致——504 个共同交易日 20080 合约-日比对 0 差异)在生效日 D 与前一交易日 P 的品种"一般水平"(合约范围内取众数;涨跌停用 D+1 交易日文件,因"收盘结算时起"的涨跌停自下一交易日生效):new_value 为空时回填(notes `new_value from param file`);old_value 为空时用 P 回填(notes `old_value from param file P`);已有值则打 `PARAMCHECK=match/mismatch(file_new=..)`;抽取员标 `direction uncertain` 且新旧值都齐的行,按新旧值重定方向(notes `direction confirmed/corrected`)。参数文件缺失的日期打 `PARAMCHECK=nofile`,合约范围为中文描述("除 1、5、9 月合约以外")无法展开的打 `noscope`。
6. **参数文件推导**(`derive_events.py`):CZCE 用每日 `FutureDataClearParams.txt`(2016-01-04 起),SHFE/INE 用同上日文件;品种一般水平 = 该日全部合约取众数(自动忽略交割月合约的加档),相邻两个交易日水平不同即生成一行(`DERIVED`,notes 记录"两日都在市的合约中有几个真的变了")。两道过滤:没有任何一个合约的值变化、只是分档合约上市/到期让众数翻转的不算事件(剔除 CZCE 54 / SHFE 37 / INE 7 条);≥4 个合约里只有 1 个变(合约进入交割月前的按月阶梯,恰好打破平票)也不算(剔除 22 / 35 / 4 条)。相邻可用日相距 >12 天(参数文件缺口,不是假期)不比较。CZCE 文件有"是否单边市"列,前后一日任一合约为 Y 的行 reason 记 `rule`。
7. **对账合并**(`reconcile.py` → `build_events.py`):SHFE/INE 推导行若有同所同品种同参数、生效日相差 ≤4 天的公告行则视为已被公告解释、丢弃;其余作为"无公告行解释的参数变动"并入,notes 链接 12 天内最近的相关公告标题(正文未抓到或抽取遗漏的公告),5 天内原路回退且无公告的涨跌停/保证金变动标 reason=`rule`(单边市规则扩板)。CZCE 推导行全部并入。最后按 (announce_date, exchange, symbol, param) 排序写出。

## 6. 使用注意

- 上期所"收盘结算时起"的涨跌停调整实际自下一交易日起生效,回测按 effective_date+1 个交易日应用涨跌停、当日结算起应用保证金。
- 节假日通知的节后恢复行是"条件恢复"(以恢复交易后第一个未出现涨跌停板的交易日结算时起),effective_date 为恢复交易首日;若节后首日出现单边市,实际恢复会顺延,此时 PARAMCHECK 会显示 mismatch。
- CZCE 派生记录只反映品种"一般月份"水平(取全部合约的众数),单合约(临近交割月)阶梯上调不在其中;fee 单位在"手续费收取方式"列出现前(2021 年前)默认按元/手,若某品种当时已是比例值需以当年公告为准。
- 上期所/能源中心 2016–2019 年的公告常按合约月份分档,contract_scope 已尽量保留原文档位;做品种级因子时建议取 `contract_scope=all` 或主力合约所在档。
- 只研究"交易所主动发文"的事件:筛 `notice_id != ''`(公告行);再去掉 `reason` 含 `rule` 的行可排除单边市规则扩板。SHFE/INE 的 `DERIVED` 行是"参数确实变了、但没有一行公告能解释"的兜底记录(多数是 `rule`),用作事件因子前请先看 notes。
- 2020 年春节通知的节后恢复行 effective_date 为公告写的 2020-01-31,而市场因疫情延长休市到 2020-02-03 才开市;这些行的 PARAMCHECK/回填用了 2020-02-03 的参数文件(notes 注明)。类似地,凡 effective_date 不是交易日(如"自 1 月 1 日起"),校验用 5 天内下一个交易日的文件。
- 2026-09-21 之后生效的行(2026 年中秋国庆通知的 9/23、9/29 上调与 10/08 条件恢复)尚无参数文件可校验(`PARAMCHECK=nofile`),恢复行的 new_value 为空。
