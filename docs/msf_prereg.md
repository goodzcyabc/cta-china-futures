# 多源基本面合成因子 MSF(演示)—— 预注册(写于 2026-10-05 北京;任何合成结果之前;试验 60)

> 性质:**工程演示 + 回顾性诊断**。所有成分在 2016–2026 上都已单独看过(二十一至二十四),合成后的回测**只能作为样本内演示,不构成证据**;证据只能来自未来纸面数据。本文第 1–7 节在合成因子的任何收益结果之前提交;运行后只在第 8 节追加。

## 1. 起因与命名
需求方(朋友,经用户转述,2026-10-05):"把新闻、天气、工业产能之类的数据聚合一下,用多个数据源组合成 alpha,而不是只依赖一个值;先做个 demo 插入系统。"他用了"世界模型"一词。**本因子不是世界模型**:AI 里的世界模型指从数据学出环境动态、用于预测与规划的模型(Ha & Schmidhuber 2018;LeCun 的 JEPA;NVIDIA 称之为 world foundation model)。本因子借鉴的是"用多源数据刻画经济状态、不依赖单一指标"的思路,方法上属于**多信号等权合成(预测组合)**:Cotter、Eyiah-Donkor & Potì (2023, J. Commodity Markets) 发现单个宏观预测变量的样本外表现多为负,而等权组合稳定为正。命名:**多源基本面合成因子(Multi-Source Fundamental composite,MSF)**。

## 3. 新成分 P 的定义
- 需求方原话:"PPI 和工业 PPI 原材料指数与 GDP 平减差值的变化率 winsorize 之后的值,反映重工业企业实际采购原材料的能力。"
- 实现(唯一版本):剪刀差 g_m = PPI 全部工业品同比 − PPIRM 同比(同一期末 m;两者同日公布,取较晚的公布日);特征 = g_m − g_{m−3}(3 个月变化);可得日 = 公布日之后第一个交易日开盘建仓(目标记在其前一交易日);扩展 z(最少 24 个月)→ clip ±2 → /2(去极值);45 日无新公布 → 失效。
- **与原话的差异及理由**:GDP 平减指数是季度数据,滞后约 6 周、与月度 PPI 混用会使信号陈旧;PPI 与 PPIRM 已是同一工业口径的出厂价与购进价,二者之差直接度量"卖出价相对买入价",不需要再减平减指数。方向按需求方的经济解释:剪刀差扩大 → 工业企业利润与采购能力改善 → 对工业品偏多。
- 已知弱点:PPIRM 本质上是滞后一个多月的原材料价格,与时序动量有循环;月频,样本约 110 个月。

## 4. 合成规则(写死)
- 每个品种每个交易日:MSF = 当日有值的成分信号的等权平均 × √(有值成分数 / 12)(与项目 `cta.signals.core.combine` 相同的 √n 归一,12 = 成分总数),clip 到 [−1, 1]。不按收益、相关性或稳定性给权重。
- 接入系统:`src/cta/factors/composite.py` 构造 MSF;`compute_signals` 新增可选参数 `extra_factors`,只有配置的 `signals.weights` 含 `msf` 时才使用;现有全部配置(含 champion v0.3)不含 `msf`,输出必须逐位不变(测试)。演示配置 `configs/strategy_v06_msf.yaml` = 时序动量 + 展期收益 + MSF 等权(MSF 取代单一的仓单因子作为系统的非量价腿),其余参数与 v0.3 完全相同。

1. **B、P 的周末公布**:沿用试验 51 的 `effective_target_day`,周六/周日 09:30 公布的 PMI/PPI 会把目标日记到前一个周五;13 个工业品都有夜盘,引擎在周五 21:00 成交——早于公布。本因子的 A、B、P 改用 `first_session_on_or_after`:目标日 = 公布日当天或之后第一个交易日(工作日公布不变;周末/节假日公布顺延,比第 3 节"公布日之后第一个交易日开盘建仓"的本意更保守一个交易时段),实盘 as-of 与回测一致。审计表新增 `publish_date`,单独检查公布日 ≤ 目标日。试验 51 的旧规则作为默认保留以便复现(该试验 103 次公布中 23 次属此情形,判定 Noise 不受影响,在设计日志 25.3 记录)。

3. 截断检查日加入周末公布前的周五(2019-06-28、2024-03-08、2024-03-29)与春节前月末(2020-01-23)。
4. 评估器 `signal_weighted_returns` 的分母实为 T+1 的波动率(含当日收益),与注释不符;为可复现试验 52–59 的 R0 不改数字,只改注释并在结果文档披露。
