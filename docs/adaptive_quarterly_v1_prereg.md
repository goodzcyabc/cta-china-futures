# 季度自适应 v1(adaptive_quarterly_v1):预注册(2026-09-25 北京;实现与运行之前写定,提交后 1–12 节不改,只在 13 节追加结果)

## 1. 研究问题
现有 v0.3(tsmom + carry + receipts_level 等权,参数 2016–2021 定死)训练期夏普 1.2–1.6、正式 OOS 拼接 0.35;carry 2022 后归零、趋势族衰减、收益集中于 2022Q1 与贵金属;已试的扩展窗口筛选与三年 carry 门控无效(19.7 已更正其边界)。问题:**一个每季度重训、有遗忘能力、三个核心因子 sleeve 权重连续可训练并强收缩的模型,能否改善 2022-01-04 → 2026-06-05 的拼接表现?若不能,失败在估计噪声还是信息不足?** 季度重训是硬要求,不再讨论是否需要。

## 2. 模型(主模型 M1 = 指数衰减夏普评分 + 等权收缩;消融 A1、A2)
记 r_{f,t} 为因子 f 的 sleeve 净日收益(因子评估器 `cta.factors.evaluate.evaluate_factor` 口径:该因子单独做多空、22 品种、协方差波动率目标 10%、总名义上限、含手续费与滑点;信号与 v0.3 流水线相同),f ∈ {tsmom, carry, receipts_level}。在训练截止 T:
- **EWMA 统计**:λ = 0.5^(1/(243·h)),h = 1 年(243 个交易日);μ_f = Σ_{t≤T} λ^{T−t} r_{f,t} / Σ λ^{T−t};σ_f² 同法(围绕 μ_f);ŝ_f = μ_f/σ_f × √243(年化夏普)。有效样本量 N_eff = (Σλ^k)²/Σλ^{2k} ≈ 701 日 ≈ 2.89 年(数据充足时),夏普标准误 ≈ 0.59。
- **评分 → 原始权重**:score_f = max(ŝ_f, 0);若 Σ score = 0 → w_raw = (1/3,1/3,1/3),否则 w_raw_f = score_f / Σ score。
- **收缩**:w_shr = (1 − κ)·w_raw + κ·(1/3,1/3,1/3),κ = 0.6。
- **上限**:w_max = 0.5;超过者截到 0.5,超出部分按其余权重比例分配(迭代直到无超限);权重非负、和为 1,隐含下限 κ/3 = 0.2。
- 冻结权重 w_T 用于下一季度全部交易日:comb_t = combine({tsmom, carry, receipts_level}, w_T)(`cta.signals.core.combine`,nan-aware 加权平均 × √(n_active/n),对权重尺度不变,因此等权 ≡ 静态 v0.3,可逐位复现)。后续波动率目标缩放、总名义上限、暴露缓冲、手数带、保证金、执行与 v0.3 完全相同,权益连续、季度边界不重置。
- **A1(消融 1,遗忘形状)**:统计量改为**硬滚动窗口 3 年**(729 个交易日等权,N_eff 与 h=1 年的 EWMA 相近)的 μ、σ,其余与 M1 相同。
- **A2(消融 2,是否需要协方差)**:μ(EWMA h=1 年,日均值)、Σ(EWMA h=1 年协方差,再向其对角阵收缩 50%);w_mv ∝ Σ⁻¹μ;负值截 0,若全 ≤ 0 → 等权;归一后同 M1 的 κ 收缩与 w_max 上限。
- 因子信号本身仍为多空;非负约束只作用于 sleeve 组合权重。季内不重估。

## 3. 全部常数与依据(只用统计可识别性、反应时间、2016–2021 数据、经济解释;不用 2022 后数据)
| 常数 | 取值 | 依据 |
|---|---|---|
| 半衰期 h | 1 年 | h=0.5 年 → N_eff 1.4 年、夏普标准误 0.83,季度决策噪声过大;h=2 年 → 5.8 年、滞后与 C3 相当;h=1 年 → 2.9 年、标准误 0.59,一个因子从夏普 1.5 归零约一年内评分减半 |
| 收缩强度 κ | 0.6 | 贝叶斯:数据权重 = τ²/(τ²+SE²)。SE = 0.59;先验离散 τ 取 0.5(经济解释:允许"一个因子失效、其余维持 ~1"的横截面差异);→ 数据权重 0.42,κ ≈ 0.6。若按 2016–2021 实测 τ_IS = 0.28(三个 sleeve 日频夏普 0.95/1.50/1.35 的标准差)则 κ ≈ 0.8,更保守;取 0.6 是为了给结构变化留出反应空间,预先承认这是偏向"有反应"的一侧 |
| 上限 w_max | 0.5 | 三个因子中任一因子不超过半个组合;保证至少两个因子实质在场 |
| 下限 | κ/3 = 0.2 | 收缩的推论,不另设 |
| A1 窗口 | 3 年 | 与 h=1 年 EWMA 的 N_eff 相近,只比较遗忘形状 |
| A2 协方差收缩 | 50% 向对角 | 三资产协方差用 N_eff≈700 估计,Ledoit–Wolf 常见强度;IS 相关 tsmom–carry 0.50、其余 ~0.1 |
| 评分 | 夏普(非均值) | 三个 sleeve 都是 10% 目标波动,夏普与均值只差常数;夏普对波动估计误差更稳 |
不做任何参数遍历;上表为唯一取值。

## 4. 数据与可得时间
与正式基线同口径:`default_stitched(official_settle=True)`、22 个生产品种、统一执行引擎、官方结算价、300 万。训练截止 T 时可得:行情/持仓量 ≤ T、主力排程(由 ≤ T 的持仓量决定)、仓单 ≤ T(交易所自 2016-01-04)、官方结算价 ≤ T、手续费/滑点参数(常数)。sleeve 收益由因果计算的信号与滚动波动率得出,程序用"截断到 T 的面板 + T 之后注入噪声"两种方式验证 T 的权重不变。

## 5. 季度排程
上下文段 2020Q1–2021Q4(8 个 vintage;权重训练同样只用 ≤ cutoff 数据),正式历史诊断 **2022Q1–2026Q2 共 18 个**;cutoff = 上一季度最后一个交易日(含),2022Q1 只用 ≤ 2021-12-31;交易区间 = 本季度交易日,2026Q2 截至 2026-06-05;引擎自 2020-01-02 空仓一次性连续运行到 2026-06-05,不每季注资、不空仓起跑;暴露缓冲状态跨季连续。

## 6. 对照组(同一数据、引擎、成本、初始资金、区间)
1 静态 v0.3;2 固定 v0.1;3 季度附加因子选择 A_Q;4 年度选择 A_Y;5 C3 门控;6 **M1**;7 A1、A2。其中 1–5 直接复用 `results/quarterly_walkforward/` 的权益(同一引擎、同一连续区间),并在本次运行中重算静态 v0.3 作一致性校验(须逐位相同)。

## 7. 主指标与逐 vintage 记录
主指标:2022-01-04 → 2026-06-05 拼接段的月频夏普、年化、最大回撤、年化成本(手续费 + 价内滑点);相对静态 v0.3 的配对日收益差:Newey–West(lag 5)年化均值/SE/t、移动块 bootstrap(块长 10、2000 次、种子 20260925)95% 区间;季度胜率(18 季);单季夏普只作记录。
每个 vintage 记录:cutoff、交易区间;每个因子训练期 EWMA 年化收益、波动、夏普、两两相关;原始权重、收缩后权重、最终冻结权重;与上季权重的 L1 变化;N_eff;下一季毛/净盈亏、手续费、滑点、换手、季内回撤;逐因子贡献(评估器口径 = 冻结权重 × sleeve 净收益,与引擎口径分开标注)、逐品种、逐板块贡献(引擎口径);相对静态 v0.3 的配对收益;权重方向与下一季因子收益是否一致(w_f − 1/3 与下一季 sleeve 净收益的符号一致数、权重-收益秩相关);carry 首次明显降权时间(w_carry < 0.25);权重集中度(HHI)与权重换手。

## 8. 判读规则(先写;全部满足才写"存在改善证据",否则写"无证据",不改参数重跑)
① OOS 月频夏普 ≥ 静态 v0.3 + 0.20;② 配对净收益 block-bootstrap 95% 区间不含 0;③ ≥ 11/18 个季度跑赢静态;④ 最大回撤不恶化超过 3 个百分点;⑤ 年化成本不超过基线的 125%;⑥ 改善(拼接段净盈亏差)不得有 > 50% 来自单一季度;⑦ 改善不得只由前三个品种贡献(去掉贡献最大的三个品种后配对差仍 > 0);⑧ 权重不频繁撞上下限(撞界季度 ≤ 50%)、不剧烈翻转(季度 L1 变化中位数 ≤ 0.3)。消融同规则。

## 9. 停止规则
静态 v0.3 不能逐位复现;截断/扰动后权重改变;cutoff 当时数据不可得 → 停止全量运行并修复。Smoke 只跑 2022Q1、2022Q2。

## 10. 模型数量与试验计数
新增模型 3 个:M1(试验 47)、A1(48)、A2(49);计数 46 → 49。不新增因子;候选因子不进入主结果。主模型 M1 在看到任何 2022 后结果前选定(依据:可解释、连续遗忘、估计噪声与反应时间的折中)。

## 11. 预计失败模式(先写)
- 强收缩 + 上限使权重只能在 [0.2, 0.5] 内变化:carry 最多从 1/3 降到 0.2,仓位变化有限,拼接差异可能小于噪声;
- EWMA 滞后约 1 年:carry 2022 归零要到 2023 年前后才被明显降权,2022 的亏损避不开;
- 若 tsmom 与 receipts_level 也同步衰减,权重再分配不产生收益,只增加换手;
- 2022Q1 的集中事件不受权重影响,改善(若有)可能仍集中于少数品种/季度;
- A2 的协方差估计噪声可能让权重比 M1 更抖。
