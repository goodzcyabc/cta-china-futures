# 另类数据五条:产区降雨、ENSO、新闻语调、上期所周库存、钢城空气质量 —— 预注册(写于 2026-10-02 北京;任何收益结果之前;试验 52–56)

> 性质:**回顾性诊断**。2016–2026 已被 51 次计数试验使用;本轮结果无论多好都不能成为生产 champion,最多为通过的候选建立未来纸面 challenger。本文第 1–10 节在数据管道建成、任何收益结果之前提交;运行后只在第 11 节追加。数据源的侦察与反向核验记录在 `docs/altdata_sources.md`(13 类、60 个子任务,全部实测下载,没有计算任何与收益的关系)。
> 来源选择规则(先写):免费、免登录、不建账号;历史 ≥ 2017 年前;每条观测的公开时间可由时间戳或发布规则确定;官方或可信来源;有经济机制;与已测过的价格类信息不同源。按这五条,13 类里能用的来源见 `docs/altdata_sources.md`;本轮只取五个假设,其余可用来源(USDA 周度出口销售/作物进度/WASDE、EIA 周报、CFTC 持仓、统计局/央行月度、运价指数)因"信息经海外期货价格传导、本项目已测过海外价格"或"独特性低"**本轮不测**,记录在第 10 节。

## 1. 试验计数与候选
当前计数 51(`docs/design_log.md` 二十一)。本轮 5 个候选各计 1 次:W = 52,E = 53,N = 54,S = 55,Q = 56;计数 51 → **56**。每个候选内部的多品种"腿"是同一试验的组成部分,不另计;不做任何窗口、方向、阈值、篮子的替代版本。

## 2. 通用约定(全部候选相同)
- **可得日 A 与目标日**:每条观测先按该来源的公开规则算出"可得日 A"(该日 15:00 北京收盘前一定已公开);目标暴露记在 **A 当日或之后的第一个交易日**,引擎在其后一个交易日开盘成交(有夜盘品种为当日 21:00)。这与上一轮"公布日之后第一个交易日开盘建仓"的语义一致,只是把"公布时刻在日内"的情形改成显式的可得日。
- **标准化(唯一版本)**:特征 f_t → 扩展窗口 z(均值与标准差只用 ≤ t 的值;最少 500 个交易日或 104 周)→ clip ±2 → /2 → 信号 ∈ [−1, 1];篮子外品种 NaN。不做其他标准化。
- **方向**:每条腿的符号在第 3–7 节写死;方向写反不翻号,如实报告。
- **执行与评价**:与 `docs/fundamental_signal_prereg.md` 第 5 节完全相同——candidate standalone / 静态正式基线 v0.3 / 50-50 事前风险预算混合,同一条 `raw_exposure → apply_buffer → run_backtest` 路径(模块 `src/cta/analysis/candidate_eval.py`,已用上一轮 PMI 候选回放验证逐位一致);生产执行口径(T 收盘定手数、手续费、1 跳滑点、换月、缓冲 0.30、手数带 0.30、10% 目标波动、1×/3×/40%、官方结算价、300 万);窗口 2016-01-04 → 2026-06-05;绩效自候选首个持仓日起;OOS 2022-01-04 起;配对差 NW 5 阶 + 块 bootstrap(块长 10、2000 次、种子 20261002)。
- **判读 R0–R14**(同上一轮第 6 节,由 `candidate_eval.evaluate` 机械计算)+ 本轮新增 **R15 家族校正**:5 个候选同时检验,"Candidate signal"还要求混合配对差的块 bootstrap **99%** 区间下限 > 0(Bonferroni 0.05/5)。四级判定 Invalid / Candidate signal / Noise / Weak evidence 的规则不变。
- **数据落盘**:原始文件按来源存 `data/external/alt/<source>/raw/`(不入 git;含每个文件的 HTTP Last-Modified),解析表 `observations.csv`(obs_date、available_day、key、value、meta);信号构造在 `src/cta/analysis/altdata_signals.py`;结果 `results/altdata_diagnostic/`;文档 `docs/altdata_diagnostic.md`。

## 3. W(试验 52):产区 90 日降雨异常 —— NOAA CPC 全球统一雨量格点
- **数据**:CPC Global Unified Gauge-Based Daily Precipitation,实时版(RT),0.5°,2006 年起(1979–2005 为回溯版、站点数不同,只用于不交易的气候基线)。取值走 PSL THREDDS NCSS 年度区域子集(与 CPC 原始二进制逐格相等,核验者在 6 个日期验证),可得时间走 CPC FTP 目录的逐日文件 Last-Modified(UTC)。
- **可得规则(核验者)**:日 D 的文件首版 D+1 ~17:25 UTC,终版 D+2 21:51 UTC(北京 D+3 05:51),2.8% 的文件在更晚被整批重写(最长 189 天),首版与被覆盖的版本都没有存档。规则:**可得日 A = max(D+4, 文件 Last-Modified 所在北京日)**;被重写的日子按重写后的值与重写时间处理(如实记录这类日子的数量)。
- **区域(经济产区,先写死;0.5° 盒子,格点均值)**:
  | 腿 | 品种 | 盒子(纬度 × 经度) | 机制 | 符号 |
  |---|---|---|---|---|
  | W-P | P 棕榈油 | 5°S–7°N, 99°E–119°E(马来半岛、沙巴/砂拉越、苏门答腊、加里曼丹) | 干旱降低油棕鲜果产量(滞后数月),市场在观测到干旱时定价 | 干 → 多(信号 = −z) |
  | W-SR | SR 白糖 | 21°N–26°N, 99°E–111°E(广西、云南南部、广东西部) | 甘蔗生长期降雨不足 → 减产 | 干 → 多(−z) |
  | W-RU | RU 橡胶 | 5°N–12°N, 98°E–103°E(泰国南部与马来北部) | 割胶季多雨 → 割胶天数减少 → 供应下降 | 湿 → 多(+z) |
  | W-AL | AL 电解铝 | 21°N–34°N, 97°E–108°E(云南、四川流域) | 水电来水不足 → 云南/四川限电 → 铝厂减产 | 干 → 多(−z) |
- **特征**:f_t = log(1 + 过去 90 日盒子均值日雨量之和) − 同一日历日(±15 日平滑)在 **2006–2015** 年的均值(气候基线只用窗口之前的实时版年份);z 为 f 的扩展 z(2008 年起,最少 500 个交易日)。90 日 = 一个季度,是产量冲击与水库蓄水的量级,不扫 30/60/180。
- **数据起点与首个信号**:雨量 2006-01 起 → f 2008 起 → z 2010 起 → 首个可交易信号 2016-01-04。
- **已知弱点(先写)**:格点为插值,马来/印尼盒子内雨量站稀疏;天气对所有参与者实时公开,D+4 已是旧信息;云南限电只有 2021–2023 几次;Roll (1984) 的教训——天气只解释期货价格方差的一小部分。

## 4. E(试验 53):ENSO —— NOAA CPC 周度 Niño 3.4 海温异常
- **数据**:`wksst8110.for`(冻结版,1981–2010 基期,1990-01-03 → 2021-01-27,核验者证实 2014-09 起 55 个 Wayback 版本逐行相同、只追加)+ `wksst9120.for`(实时版,1991–2020 基期)。2021-02-03 起优先用 Wayback 首次刊出的版本,无版本的周用当前文件(核验者:2021-09-22 → 12-01 约 11 周无首印;v2.1 下近 3 周偶有 ±0.1 修订;如实记录)。
- **拼接**:x_t = Niño 3.4 异常;2021-02-03 起的实时版减去常数 c = (实时版 − 冻结版)在 2016-01 → 2021-01 重叠期的均值(核验者测得均值 −0.03、标准差 0.19),使水平连续;不重算气候基线。
- **可得规则(核验者)**:行日期是周中周三 W;文件在下周一生成(2013–2023 年中为 10:56/11:58 UTC = 北京 18:56/19:58,2023-08 起 06:56 UTC = 14:56,2026 年 07:00:12 UTC = 15:00:12,周一收盘是竞态);**可得日 A = W + 7 日(下周三)**,每周一个目标日。
- **腿与符号**:篮子 {P, SR},两腿同一信号:z 为 x 的扩展 z(1990 年起,最少 104 周),**正(厄尔尼诺)→ 多**。机制:厄尔尼诺 → 东南亚干旱 → 油棕减产;印度/泰国甘蔗减产(Brunner 2002;Ubilava & Holt 2013;Iizumi 等 2014)。不含 M/C/CF(文献方向混杂)。
- **已知弱点**:2016–2026 只有约 3 次厄尔尼诺、4 次拉尼娜,独立观测极少;ENSO 是头条新闻,日频 OISST 一天延迟即可得,周度数据可能已被定价;只影响 2 个品种。

## 5. N(试验 54):新闻语调 —— GDELT DOC 2.0 API
- **数据**:`timelinetone` 与 `timelinevolraw`(日频,UTC 日,2017-01-01 起;核验者用 9 个 Wayback 快照证实已完成日期的数值在 2020–2026 间不变;无 2016 年)。查询 = 每个品种一个**固定英文短语**(全球来源、不限语言;中文关键词版本在侦察中计数稀疏,不用):AU "gold price"、AG "silver price"、CU "copper price"、AL "aluminium price"、NI "nickel price"、SN "tin price"、I "iron ore"、J "coking coal"、RB "steel rebar"、MA "methanol"、RU "natural rubber"、SA "soda ash"、TA "purified terephthalic acid"、V "polyvinyl chloride"、SC "crude oil"、C "corn futures"、CF "cotton futures"、JD "egg prices"、M "soybean meal"、P "palm oil"、SR "sugar futures"、Y "soybean oil"。
- **篮子纳入规则(看计数不看收益)**:2017–2019 该短语 `timelinevolraw` 日中位数 ≥ 20 篇的品种进入篮子;否则剔除并记录。
- **特征**:f_t = mean(tone, 过去 7 日) − mean(tone, 过去 90 日)(短期语调相对其季度基线的变化;新闻情绪效应持续数日,7 日平滑降噪、90 日基线去掉来源构成的漂移;不扫窗口);缺失日(API 空洞:2017-12-01/02、2020-10-20、2023-03-23、2025-06-15 → 07-01 等)不填补,滚动均值按可用日计,少于 4 个可用日的 7 日窗 → NaN。z 为 f 的扩展 z(最少 500 个交易日)。**可得日 A = UTC 日 D + 2**(核验者:实时索引滞后不定,历史用 T−2 保守)。
- **符号**:语调上升 → 多(+z),全部腿同号。机制:新闻语调包含尚未入价的供需/政策信息(Brandt & Gao 2019;Elshendy 等 2018);对中国商品方向未经证实,如实报告。
- **已知弱点**:2 日滞后对日频情绪信号可能过长;GDELT 覆盖量 2017 → 2026 下降 4.5 倍、2023-03/04 中文来源断档(语调均值而非计数,受影响较小但仍记录);无版本档案,只能从现在起自存快照;首个信号约 2019-04(90 日基线 + 2 年 z)。

## 6. S(试验 55):上期所库存周报 —— 非仓单可交割库存
- **数据**:`{YYYYMMDD}weeklystock.dat`(JSON,2014-05-23 → 2025-11-14)与 `weeklystock_{YYYYMMDD}/ZH/all.html`(2025-10-31 起);字段 小计(SPOTWGHTS,全部可交割库存)与 期货(WRTWGHTS,仓单)。核验者:187 对连续周"上周"字段与前一周"本周"字段完全一致、无数值修订;文件会原地重写但内容未变。
- **特征**:x = log(1 + (小计 − 期货))(非仓单库存,吨),每周报告日 R;z 为 x 的扩展 z(最少 104 周)。信号 = **−z**(库存越高越空;theory of storage,Gorton–Hayashi–Rouwenhorst 2013)。
- **篮子**:{CU, AL, NI, SN, RU}(有 小计 列的品种;AU/AG/RB/SC 只有仓单列,与已用的 receipts_level 相同,不入)。核验者测得仓单占比中位 CU 0.38、AL 0.55、NI 0.85、SN 0.92、RU 0.91,即新信息主要在 CU、AL;仍按经济定义取五个,不按占比挑。
- **可得规则(核验者)**:报告日 R 当天 15:13–18:05 公布(2024-07 起有嵌入时间戳;2016–2023 只能证明 ≤ 20:55);**可得日 A = R 之后第一个交易日**(周一收盘用,周一夜盘成交),不用同周五夜盘。
- **已知弱点**:橡胶每年 11 月老胶仓单注销造成库存断崖(非仓单部分也受影响;不做季节处理,如实记录);指定仓库数量随时间增加,水平序列非同质;财联社/SMM 在公布后 30 分钟内转发,无信息获取优势;每品种约 590 周。

## 7. Q(试验 56):河北钢城空气质量 —— 限产代理
- **数据**:中国环境监测总站实时城市小时数据的第三方逐日存档 `quotsoft.net/air/data/china_cities_YYYYMMDD.csv`(2014-05-13 起;核验者:2016 年文件与哈佛 Dataverse 2017-01 冻结副本逐字节相同、2019-04-01 与 Wayback 相同;许可证存疑——Dataverse README 写"非商业",本轮只作研究诊断,写入报告)。
- **城市**:唐山、邯郸、石家庄、邢台(河北"2+26"钢铁集中城市)。**变量用 PM2.5 原始浓度**,不用 AQI(核验者:2026-03 起 AQI 规则可能更改;2018-09-01 气体参比状态变更不影响 PM2.5 的"实况"口径)。
- **特征**:日值 = 当日可用小时 PM2.5 的均值(北京日历日;缺少 ≥ 8 小时的日 → NaN);f_t = log(四城日值均值 的过去 7 日均值);z 为 f 的扩展 z(2015-01 起,最少 500 个交易日)。信号:**RB +z,I −z,J −z**(重污染 → 应急限产 → 钢材供应减少、炉料需求减少;CRU 2017、唐山 2021-03 案例)。不做季节调整:机制本身集中在采暖季。
- **可得规则(核验者)**:日 D 的小时值在 D+1 的 00:23–00:53 北京前写完,**可得日 A = D + 1**;不用当日小时值。
- **已知弱点**:实况污染滞后于预警通知(交易员直接读通知);AQI/PM2.5 主要由天气决定;限产政策从"一刀切"(2016–2018)到绩效分级(2019–2020)再到产量平控(2021 起),机制随时间变化;单一个人服务器;许可证。

## 8. 停止规则
基线不能逐位复现;任一候选的点时审计失败(可得日 < 数据日,或目标日之前已用到未公开的值);数据管道在 cutoff 当时不可得的字段(例如 CPC 文件在重写日之前的值)被当成可得;GDELT 篮子纳入规则执行时看到了任何收益 → 停止、修复、重跑 smoke。

## 10. 预计失败模式与本轮不测的来源(先写)
- 共同:天气与库存都是公开、被广泛盯着的信息,滞后 1–4 日后多半已入价;5 个候选 × 多腿,多重比较由 R15 控制,仍可能有一两个"弱证据";2016–2026 行业整体走弱惩罚多头偏向。
- W:格点插值与站点稀疏;90 日窗口对割胶(周级)偏长、对水库蓄水(季级)偏短;机制只在部分年份有效(云南 2021–2023)。E:独立观测 ≤ 7 次;只 2 个品种。N:2 日滞后;覆盖量非平稳;英文短语对中国定价品种(RB、J、SA、V、MA)的相关性弱。S:与已用的仓单高度相关(水平相关 0.93–0.99);新信息集中在 CU/AL。Q:实况滞后预警;机制随政策变化;许可证风险使其即便通过也难上线。
- 本轮不测(可用但不选)及理由:USDA 出口销售/作物进度/WASDE、EIA 周报、CFTC/ICE 持仓(经 CBOT/NYMEX/ICE 价格传导,本项目外盘价格因子已测无增量;独特性低);统计局/央行月度数据(独特性低、月频);波罗的海运价(非官方镜像、许可);CHIRPS(2026 年底停产、首版无档);IMF PortWatch(2019 年起,历史不足);国家粮食交易中心、发改委新闻稿、农业农村部批发价、维基百科浏览量、NASA POWER(核验者否决)。
