# 架构

目标:一个从研究到实盘**同一条代码路径**的商品期货 CTA 系统。研究回测和每日出单调用同一套数据层、信号层、组合层;区别只在"截至哪一天"。

```
configs/            instruments.yaml(合约参数)、strategy.yaml(策略参数,带版本)
src/cta/
  data/             DataSource 协议 + 实现(RicequantParquet 研究用;LiveVendor 上线替换)。产出合约级日线与主力映射
  instruments/      合约参数模型:乘数、跳价、保证金、手续费、涨跌停;所有成本计算的唯一来源
  continuous/       换月规则(主力切换 + N 日确认)、回溯复权连续价、近月/次近月对
  signals/          纯函数:时序动量、展期收益、波动率、合成、波动率目标、交易缓冲
  portfolio/        目标名义暴露 -> 整数手数;保证金占用、杠杆、单品种上限;换月交易
  backtest/         日频引擎:次日开盘成交、按跳滑点、按合约手续费、涨跌停不可成交、保证金占用与可用资金
  risk/             绩效指标(日频/月频、NW t)、回撤控制、暴露与归因
  live/             按 as-of 日生成目标手数与订单差异;输入快照与哈希;状态文件读写
  report/           表格与图
  cli.py            cta download | research | live
tests/              单测(纯函数)、引擎机制测试、无前视扰动测试、回归测试(冻结期望输出)
docs/               本文件、design_log.md(预注册)、deployment.md(上线清单)
```

## 关键约定

1. **信号只看回溯复权连续价,成交只看真实合约价。** 连续价用于收益率与信号;名义金额、保证金、手续费、滑点一律按当日实际持有合约的价格与乘数计算。
2. **T 日收盘算信号,T+1 开盘成交。** 不存在同价算分又同价成交。
3. **换月由数据决定,不由日历决定。** 主力合约按持仓量切换并需连续 N 日确认;切换日同时平旧开新,两笔都计成本。
4. **无写死的成本。** 一切来自 instruments.yaml,并带 verified 标记。
5. **每次运行有指纹。** 配置哈希、数据清单哈希、git SHA 写入结果与订单快照。
6. **研究脚本不进包。** `src/cta` 只放会上线的代码;探索性分析放 `scripts/`,输出到 `results/`。


## 因子研究层(v0.2 起)
`cta.factors`:`base`(输入容器、规格、注册表、统一标准化)、`library`(候选因子,一个 id 一个定义,窗口写死)、`evaluate`(单因子波动率目标组合、成本、TS/XS-IC、逐年、Deflated Sharpe)。研究脚本在 `scripts/factor_*.py`,默认只能跑样本内(≤2021-12-31),样本外要显式 `--confirm-holdout`。生产信号仍只在 `cta.signals`;因子进入生产必须经过设计日志的选入规则与 version 递增。
