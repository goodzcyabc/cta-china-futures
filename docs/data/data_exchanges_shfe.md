# 上期所(SHFE)/ 上期能源(INE)公开日频数据接入

模块:`src/cta/data/exchanges/shfe.py`(解析、下载、落盘、回填、CLI),`src/cta/data/exchanges/ine.py`(同一套接口,只换域名与交易所标签)。
公共字段与存储布局见 `src/cta/data/exchanges/base.py`;测试与截断样例见 `tests/test_exchanges_shfe.py`、`tests/fixtures/exchanges/{shfe,ine}/`。

```
PYTHONPATH=src python3 -m cta.data.exchanges.shfe backfill --start 2016-01-04 --end 2026-09-16 --kinds quotes,positions,receipts
PYTHONPATH=src python3 -m cta.data.exchanges.ine  backfill --start 2018-03-26 --end 2026-09-16 --kinds quotes,positions,receipts
PYTHONPATH=src python3 -m cta.data.exchanges.shfe day --date 2026-09-16          # 每日增量
PYTHONPATH=src python3 -m cta.data.exchanges.shfe coverage                       # 每类每年落盘天数
```

回填逐工作日进行:周末不请求;HTTP 404(节假日 / 尚未发布)与空内容记入 `data/exchanges/<EXCH>/missing.log`(`日期\t类型\t原因\tURL`),下次运行跳过(`--retry-missing` 重试);已有 parquet 跳过;每次请求间隔 ≥0.5 s,非 404 失败按 1/2/4 s 退避重试 3 次,连续 10 天失败中止。当天(`date >= today`)的 404 不写 missing.log,因为可能只是还没发布。原始下载 gzip 存 `raw/`,`--overwrite` 可从 raw 重新解析。

## URL 模式(User-Agent 需为桌面浏览器;两站 `.dat` 均可直接 curl,INE 的 HTML 页面才有 WAF)

| 数据 | SHFE | INE | 起始 | 说明 |
|---|---|---|---|---|
| 日行情 | `https://www.shfe.com.cn/data/tradedata/future/dailydata/kx{YYYYMMDD}.dat` | `https://www.ine.cn/data/tradedata/future/dailydata/kx{YYYYMMDD}.dat` | 2016-01-04 / 2018-03-26 | JSON,`o_curinstrument` |
| 会员成交持仓排名 | `…/dailydata/pm{YYYYMMDD}.dat` | 同 | 2016-01-04 / 2018-03-26 | JSON,`o_cursor` |
| 仓单日报(旧) | `…/dailydata/{YYYYMMDD}dailystock.dat` | 同 | 2016-01-04 … 2025-11-17 | JSON,`o_cursor`;2025-11-18 起 404 |
| 仓单日报(新) | `https://www.shfe.com.cn/data/tradedata/future/stockdata/dailystock_{YYYYMMDD}/ZH/all.html` | 同上(INE 也从上期所域名取,见下) | 2025-11-13 起 | HTML 表格;两站文件内容完全相同(上期所 + 能源中心全部品种) |

仓单日报的新接口是在官网"数据 → 日周数据 → 仓单日报"标签页点击后由浏览器请求捕获到的;
试过而无效的候选:`/data/dailydata/{d}dailystock.dat`(旧站,现 404)、`/data/tradedata/future/stockdata/{d}dailystock.dat`、`…/stockdata/dailystock_{d}/ZH/all.dat|.json`、`…/dailydata/dailystock_{d}/ZH/all.html`。
新旧接口重叠区间 2025-11-13 … 2025-11-17(两者都有,内容一致);模块常量 `RECEIPT_HTML_FROM = 2025-11-13`、`RECEIPT_DAT_UNTIL = 2025-11-17`,回填时先按日期选主接口,失败再试另一个。
`ine.cn` 上同一路径的 HTML 被其 WAF("WEB 应用防火墙" JS 挑战页,HTTP 200 但正文约 10 KB 无表格)拦截,curl 与本模块都拿不到;因为两站文件逐字节相同(2026-09-15 对比),INE 的新版仓单直接从 `www.shfe.com.cn` 取(`Site.receipts_html_base`),再按品种归属只保留能源中心品种。

上期所与能源中心是同一套系统:**上期所的 kx 与仓单文件里也包含能源中心品种(sc/nr/lu/bc/ec)**,pm 文件则各自只含本所品种。
模块按品种归属拆分:`INE_SYMBOLS = {SC, LU, NR, BC, EC}`,SHFE 解析时剔除、INE 解析时只保留,保证每个交易所目录下只有本所合约、不重复。新上市的能源中心品种要加进这个集合。

## 字段映射

### 行情 `quotes`(每行一个期货合约)

保留条件:`PRODUCTID` 以 `_f` 结尾且 `DELIVERYMONTH` 为 4 位数字。由此剔除:`小计`(品种小计)、`总计`、`efp`(期转现,如 `snefp`/`ruefp`/`agefp`)、`sc_tas`(原油 TAS 指令,PRODUCTCLASS=6)。期权不在 kx 文件里(另有文件)。

| 规范列 | 来源字段 | 说明 |
|---|---|---|
| contract | `PRODUCTGROUPID`(2021-06 起有)或 `PRODUCTID[:-2]` + `DELIVERYMONTH` | `normalize_contract` → `CU2610` |
| symbol | 上式的品种部分大写 | |
| open/high/low/close | `OPENPRICE/HIGHESTPRICE/LOWESTPRICE/CLOSEPRICE` | 无成交时为空串 → NaN(base.validate 再统一置 NaN) |
| settle / prev_settle | `SETTLEMENTPRICE` / `PRESETTLEMENTPRICE` | settle 为空时用 close→prev_settle 补并记 warning(回填中未出现) |
| volume / open_interest | `VOLUME` / `OPENINTEREST` | 交易所原值(手),口径见下;2018–2019 年部分无成交合约的 `VOLUME` 留空(而非 0)→ NaN,共 1,844 行(SN/WR/FU 居多),OI 均为 0 |
| turnover | `TURNOVER` | **单位万元**,交易所原值;字段 **2021-07-28** 起才逐合约提供(`TURNOVER_FROM`,两所同日),之前 NaN |

旧文件(2016–2020)的 `PRODUCTID`/`PRODUCTNAME` 带尾随空格,已 strip。

### 会员成交持仓排名 `positions`(每行 = 某合约某名次的三榜并排)

| 规范列 | 来源字段 | 说明 |
|---|---|---|
| contract | `INSTRUMENTID` | `cu2610` → `CU2610`;品种合计 `cuall`(2016 年叫 `cuactv`)→ contract 记为品种代码 `CU` |
| rank / is_total | `RANK` | 1–20 为名次;`-1` 期货公司会员合计、`0` 非期货公司会员合计、`999` 前 20 名合计 → `is_total=True, rank=0`,member_* 列写 `期货公司会员` / `非期货公司会员` / `合计` |
| member_vol, vol, vol_chg | `PARTICIPANTABBR1, CJ1, CJ1_CHG` | 成交量榜 |
| member_long, long_oi, long_chg | `PARTICIPANTABBR2, CJ2, CJ2_CHG` | 持买单量榜 |
| member_short, short_oi, short_chg | `PARTICIPANTABBR3, CJ3, CJ3_CHG` | 持卖单量榜 |

三榜行数不一定相同(某榜不足 20 家时该行对应列为空 → member 为 None、数值 NaN)。`合计` 行等于前 20 名之和(抽查 CU1807 2018-06-01 三榜均相等)。
文件格式在 **2016-12-19** 变过一次:之前每个合约都有 `-1/0`(期货公司/非期货公司)合计行,品种合计叫 `cuactv` 且带完整前 20 名排名;之后合约级只剩 `1–20 + 999`,品种合计改叫 `cuall` 且只有 `-1/0` 两行(品种层面的期货公司/非期货公司总成交、总买、总卖),没有排名。规范化后两种格式落到同一套列上,靠 `contract == symbol` 区分品种合计行。
公布标准(上期所"各期货品种交易成交持仓公布标准",2025-06-05 版):合约持仓量达到阈值才公布该合约排名(铜 1.5 万手、螺纹钢 10 万手、天然橡胶 5000 手……;能源中心 原油 10 万手、20 号胶 2 万手、低硫燃料油 5 万手、铜(BC)1.5 万手、欧线 3 万手,均单边)。
**因此 INE 的原油(SC)排名几乎从不公布**(单合约持仓极少达到 10 万手),INE 2018–2020 的 pm 文件为空,2021 起只有 nr/lu/bc/ec。

### 仓单日报 `receipts`(每行 = 某品种某仓库,或合计)

| 规范列 | 旧 JSON 来源 | 新 HTML 来源 | 说明 |
|---|---|---|---|
| symbol | `VARID`(2022 起)否则 `VARNAME` 中文名映射 `RECEIPT_SYMBOLS` | 品种标题行文字映射 | `螺纹钢厂库`/`氧化铝(仓库)` 等先去掉 仓库/厂库 后缀再映射 |
| warehouse | `WHABBRNAME`(`$$` 前中文) | 仓库列 | 厂库表的仓库名加后缀 `(厂库)`,与同名仓库区分 |
| is_total | `ROWSTATUS` 1(地区合计)/ 2(品种总计) | `isTotal` 行 | 地区合计 warehouse 记为 `{地区}合计`(如 `上海合计`);品种总计为 `保税商品总计` / `完税商品总计` / `总计`(厂库表只有地区合计,如 `厂库提货地合计(厂库)`) |
| receipts / change | `WRTWGHTS` / `WRTCHANGE` | 期货 / 增减 列 | 交易所原值;**单位:黄金、白银 千克,原油 桶,其余 吨**(`WGHTUNIT` 1/3/2) |

取某品种当日注册仓单总量:最稳的是 `~is_total` 的仓库行按 symbol 求和(黄金只有一行 `上期所交割库`、没有任何合计行;厂库表也只有地区合计没有 `总计`)。若用合计行:`warehouse=="总计"` 只覆盖仓库表,仓库+厂库两张表的品种(RB/HC/BU/SP/AO/BR/LU/SS/NR/OP)还要加上 `…合计(厂库)`。

## 成交量 / 持仓量口径

- 上期所、能源中心自 **2020-01-01** 起把成交量、持仓量统计口径由"双边"改为"单边"(上期所 2019-10-29 公告,证监会统一安排;`SINGLE_SIDED_FROM`)。
  2019-12-31 及以前的文件是双边数,2020-01-02 起是单边数;交易所网站历史数据不回溯改写。
- 规范化数据**保存交易所原值,不折算**。跨 2020 年比较成交/持仓时需自行把 2020 年前的数除以 2。
- 米筐导出(`data/ricecta`)的口径:重叠区间逐合约对账(下文)显示 2020 年前后 volume/OI 与交易所原值**逐值相等**,即米筐也是"交易所原值、不折算"的口径(2019-12-31 CU2002 持仓 239,454 双边;2020-01-02 110,353 单边,两边都一致;若按"折算成单边"假设去对,2020 年前的匹配率为 0)。

## 已知坑

- 上期所 kx/仓单文件混有能源中心品种;pm 文件不混。见 `INE_SYMBOLS`。
- 2021-07-28 之前的 kx 没有逐合约 `TURNOVER`,只有品种级 `o_curproduct.TURNOVER`(亿元)——未入库。
- 旧 JSON 字段值类型不稳定:同一字段有的日期是数字、有的是字符串(如 2020 年仓单 `WRTWGHTS` 为字符串),解析统一走 `_num`。
- 仓单旧 JSON 的 `VARID`/`WHTYPE` 2022 年前为空,只能靠中文名映射;品种改名(`沥青仓库` → `石油沥青仓库`、`螺纹钢` → `螺纹钢仓库/厂库`)都映射到同一代码,但 warehouse 后缀会随之变化。名字表里没有的新品种会被跳过并记 warning。
- 仓单新 HTML 里同一品种的仓库/厂库是两张独立的表(`铜` 与 `螺纹钢(厂库)`);厂库表的"地区"列是 `厂库提货地`。
- 能源中心 `.dat` 可直接 curl;`ine.cn` 的 HTML 页面有 WAF,若将来 `.dat` 也被拦(200 但返回挑战页),模块把"非 JSON 的 200"当下载失败重试而不是当缺数据。
- 行情 `settle` 在 base.validate 里必须 > 0;上期所极少数新挂牌合约 settle 为空时模块用 close/prev_settle 补并打 warning(本次回填未出现)。
- `Store.write_day` 永不覆盖;修解析 bug 后用 `backfill --overwrite` 从 raw 重建。
- 日行情约 15:30 发布,仓单/排名约 15:00–20:00 发布(历史文件 `update_date` 多为 20:00 左右);当天增量建议 20:30 后跑。
