# 季度 walk-forward 诊断:预注册(2026-09-25 北京;运行前写定,运行后 1–7 节不改)

> 性质:**后验提出的历史 walk-forward 诊断**——两个实验的假设都来自看过 2016–2026 结果之后,因此不是新的纯净样本外;目的不是证明季度重训有效,而是定位模型在哪里失效。不改纸面账、生产配置、champion、正式报告;不做参数搜索;看到结果后不更换窗口、门槛或候选因子。实验 A、B 的定义与设计日志十九的试验 45、46 相同(本次为带完整逐季记录的重新执行,不新增试验计数)。

## 1. 现状核验(2026-09-25 读 design_log 4.4/6.2/14.2/17.8/十八、factor_walkforward.md、settle_baseline.md、report_v0.4.md 及信号/风控/执行代码)
**每日更新(不需要"训练")**:四个回看期的时序动量与 40 日实现波动率、展期收益(主力 − 次主力年化,tanh 压缩)、仓单水平(252 日自身分位 → 横截面 z)、可投掩码(历史长度 + 20 日主力成交额)、T+1 排程合约、40 日协方差的事前波动率缩放系数、总名义上限、暴露缓冲状态、手数带、保证金缩减。
**真正固定的参数**(2016–2021 样本内试验定下,此后未动):回看期 (21,63,126,252)、vol_window 40、carry_scale 0.20、因子等权(含 √n 归一)、目标波动 10%、单品种 1×/总名义 3×/保证金 40%、暴露缓冲 0.30、手数带 0.30、滑点 1 跳、换月确认 3 日、22 个品种、v0.3 的因子集合 {tsmom, carry, receipts_level}。
**可以在季度末重新决定的**(按现有规则):① 4.4 规则下的**附加因子集合**(tsmom、carry 永远保留,规则无法删除或降低 carry);② 已登记的 C3 规则下的 **carry 权重**(1 或 0.5,不归零)。除此之外没有任何"可训练"对象——权重、回看期、门槛都不在重训范围内(用户已确认不拟合权重)。
**因此**:"季度重跑现有筛选器"(实验 A)只能回答"季度筛选是否优于年度筛选",**不能**称为处理 carry 衰退的完整重训;carry 衰退由实验 B 单独检验。

## 2. 实验 A:季度筛选频率(试验 45)
- 候选集合 = 6.2 原始集合:`ALL_FACTORS` 中 11 个非参照因子 {ewmac, breakout, reversal_st, basis_mom, skew_neg, oi_growth, seasonal, carry_xs, mom_xs, lowrisk_xs, htfc_a19};基线 tsmom、carry 为因子库参照实现。
- 选入规则 = 4.4 / 6.2 脚本 `select()` 逐字:训练窗口 2016-01-04 → cutoff(扩展);月频夏普 ≥ 0.40、月频 NW t ≥ 2.0、与 v0.1 组合日收益相关 ≤ 0.60、有仓位年份中为正的年数 ≥ max(4·n//5, 3)、与已选因子两两相关 ≤ 0.80;按夏普从高到低逐个判定。
- 三臂,同一拼接与引擎:Q = 每季度末重选;Y = 每年 12-31 重选、冻结四个季度(现有年度流程);S = 固定 v0.1。选中因子与 tsmom、carry **等权**(含 √n 归一)。
- 只回答"季度筛选是否优于年度筛选 / 固定"。

## 3. 实验 B:carry 衰退(试验 46,规则 = 设计日志第 194 行已登记的 C3)
- 每季度末计算 carry sleeve 截至当时**过去 3 年**(cutoff − 3 年 + 1 天 → cutoff)的**净**月频夏普(因子评估器,v0.3 配置、22 品种、含手续费与滑点);≤ 0 → 下一季度 carry 权重 0.5,否则 1.0;不归零。
- 其他因子(tsmom、receipts_level 权重 1)、品种池、执行、风控与 v0.3 完全相同;对照 = 静态 v0.3。

## 4. 日期、数据与可得性
- 季度模型(vintage):上下文段 2020Q1–2021Q4(8 个,用于观察 IS/OOS 差距在早期 vintage 是否已出现),正式样本外段 **2022Q1–2026Q2 共 18 个**(2026Q2 交易区间截至正式 OOS 末日 2026-06-05)。
- 训练截止 = 上一季度最后一个交易日(含);**2022Q1 模型只用 ≤ 2021-12-31 的数据**,以此类推;交易区间 = 该季度第一个交易日 → 最后一个交易日(≤ 2026-06-05);配置在季内冻结。
- 实现:逐季决定 → 该季的合成信号按季拼接(程序断言无重叠、无遗漏、季内冻结)→ 在拼接序列上连续做波动率目标缩放、总名义上限、暴露缓冲 → 引擎从 **2020-01-02 空仓**连续运行到 2026-06-05(不是逐段起跑);所有臂完全相同处理。
- 数据:与正式基线同口径(`default_stitched(official_settle=True)`、22 品种、统一执行引擎、官方结算价、300 万)。在每个 cutoff 当时可得的输入:行情/持仓量 ≤ cutoff,主力排程(由 ≤ cutoff 的持仓量决定),仓单 ≤ cutoff(交易所自 2016 起),官方结算价 ≤ cutoff;不用 5 分钟线、现货、外盘。
- 训练窗口相互重叠(扩展窗口),**18 个 vintage 不是 18 个独立实验**;所有区间统计以拼接后的日/月收益为准。

## 5. 逐季记录(每个 vintage、每臂)
训练截止日与交易区间;训练期每个候选与 tsmom/carry 的月频夏普、NW t、与 v0.1 组合相关、正收益年数/有仓位年数、换手、成本;选中因子与下一季冻结权重;与上一季的集合/权重变化;下一季**引擎口径**毛盈亏(Σ逐品种盯市 + 已实现)、手续费、滑点、净盈亏、名义换手、季内最大回撤、成交笔数;下一季逐品种、逐板块净贡献(引擎口径,手续费按品种归属);逐因子 sleeve 的下一季净收益与夏普(评估器口径,与引擎口径分开标注);相对静态基线的逐日与季度配对差;被选中与未被选中候选的下一季 sleeve 表现;carry 训练期 3 年夏普、下一季权重、下一季 carry sleeve 表现。

## 6. 指标与判读规则(先写)
- **主指标**:2022-01-04 → 2026-06-05 拼接段的日/月收益(引擎连续运行切段):月频夏普、年化、最大回撤;相对基线的**配对日收益差**:Newey–West(lag 5)年化均值、SE、t,移动块 bootstrap(块长 10、2000 次、种子 20260925)95% 区间;**季度胜率** = 动态臂季度净收益高于基线的季度占比(18 个,重叠训练);次指标 = 6.2 口径评估器拼接月夏普。2020Q1–2021Q4 段只作上下文。
- **不用单季夏普作主要证据**(3 个月夏普的标准误约 ±2)。
- 判读(逐条对应"需要定位的问题"):
  1. 净增益:仅当配对差年化均值的 bootstrap 95% 区间不含 0 **且**季度胜率 ≥ 60% 才写"有净增益";否则写"无证据"。
  2. IS/OOS 下降是否在 vintage 中重复:统计"下一季实现夏普 < 训练期夏普"的 vintage 比例;**预先声明**:即使模型无衰退,这个比例也会因单季噪声而 ≥ 70%,所以它本身不构成证据;有信息量的是"训练期夏普均值 vs 拼接段实现夏普"这一对数,以及逐因子 sleeve 的训练期 vs 拼接段对比。
  3. 下降来源:逐因子 sleeve(训练期 vs 拼接段)、成本占比 = (毛 − 净)/|毛|、逐品种/板块集中度(前 3 占正贡献比例)、逐年集中度。
  4. 抖动:因子集合变化次数 / 季度数 > 40% 记"剧烈";carry 权重切换次数同理。
  5. 追涨杀跌 / winner's curse:被选中候选的下一季 sleeve 夏普均值 < 未选中候选的均值 → 记"选择后表现更差(winner's curse 迹象)";动态臂配对差 < 0 且季度胜率 < 45% → 记"重训追涨杀跌迹象"。
  6. 共同环境:静态臂、动态臂、纯 tsmom sleeve、排排网量化 CTA 趋势指数的逐年表现同向下滑 → 记"共同环境主导"。
  7. carry 降权:只看权重 = 0.5 的季度里动态 vs 静态的差;这类季度 < 4 个 → 写"样本不足,不能判断",不得用总样本差替代。
  8. 2022Q1:逐因子、逐品种归因;前 3 品种占正贡献 ≥ 70% 且 tsmom sleeve 贡献 ≥ 80% → 记"单一趋势行情驱动"。
- 事实、统计不确定性、推断在报告里分节写。

## 7. 测试与 smoke 门槛(全部通过后才跑全部季度)
测试:① 截断 cutoff 之后的数据(以及在 cutoff 之后注入扰动)后,当季选择、训练统计与权重完全不变;② 每个模型只用 cutoff 当日及以前的数据(截断面板末日 = cutoff);③ 权重/因子集合在下一季度内冻结(拼接序列逐日等于冻结值);④ 拼接区间无重叠、无遗漏;⑤ 相同配置重复运行结果逐位一致;⑥ 静态基线复现现有报告数字(v0.3、2016 起、官方结算价:月频夏普 1.077、权益终值与 `results/settle_baseline` D 臂一致)。
Smoke:只跑 2022Q1、2022Q2。若 ⑥ 不能复现、① 发现前视、或 cutoff 当时数据不可得 → 立即停止,报告原因,不跑全量。
