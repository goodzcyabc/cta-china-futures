# 商品期权隐含信息三条:偏度、方差风险溢价、去趋势隐含波动率 —— 预注册(写于 2026-10-04 北京;任何收益结果之前;试验 57–59)

> 性质:**回顾性诊断**。2016–2026 已被 56 次计数试验使用;本轮结果无论多好都不能成为生产 champion,最多建立未来纸面 challenger。第 1–10 节在数据管道建成与任何收益结果之前提交;运行后只在第 11 节追加。

## 1. 起因:米筐 RQData 能提供什么
用户 2026-10-04 给出 RQData Python 文档并要求"试着用一下找找 alpha"。逐模块核对(本地文档副本 `data/ricecta/doc/rqdata_python_*.md` 与朋友账号的接口测试记录 `data/ricecta/data_samples*/`):
- **期货模块**(主力、合约、复权、交易参数、会员排名、仓单、展期收益、指数期货基差)与**现货**(上海金交所金银)、**宏观**(83 个指标):本项目已有等价数据,且大多已检验(会员排名判死、仓单已在 v0.3、展期收益 = carry、现货基差方向反、PMI 无效)。
- **另类数据**(一致预期、新闻情绪、ESG):只覆盖股票,与商品期货无关。
- **期权模块**(`options.get_greeks` 逐合约 IV/Delta、`options.get_indicators` 的成交额/持仓/成交量 PCR、±0.25 delta IV 与 skew):**唯一的新信息**。商品期权自 2017 年起陆续上市,本项目从未使用过。
- 朋友的 RQData 账号是**试用 license**(测试记录显示剩余 17 天、1 GB 流量),本机没有安装也没有授权;本仓库不输入任何账号。为此写了 `scripts/rqdata_export_options.py`,持有授权的人运行即可导出全部商品期权指标。
- 期权日行情由交易所免费公布(侦察与核验见第 2 节),所以本轮先用交易所官方数据检验;RQData 导出若日后提供,只用于补齐大商所品种与交叉核对,不用于重新选择定义。

## 3. 通用约定(三条候选相同)
- **品种**:{CU, RU, AU, AL, SC, AG, RB, NI, SN, SR, CF, MA, TA, SA},各自自期权上市起。
- **可得规则**:日 T 的期权数据 → **可得日 = T 之后第一个交易日**(T+1 收盘出信号,T+1 夜盘或 T+2 开盘成交)。标的期货价格只用 ≤ T 的数据(T 收盘可得,不额外延后)。
- **系列选择(每品种每日)**:候选系列 = 标的期货交割月 ≥ T 所在月 + 2 的系列(保证距期权到期约 3 周以上;上期所期权在交割月前一月倒数第 5 个交易日到期,郑商所在前一月第 3 个交易日前后);其中取当日**期权总持仓最大**的系列;该系列当日期权总成交量为 0 → 当日无值。
- **标的价**:该系列标的期货合约当日官方结算价(项目交易所数据);缺失 → 当日无值。
- **隐含波动率**:上期所/能源中心用 Black-76(r = 1.5%,与交易所一致;到期 τ = (到期日 − T + 1)/365,到期日取自 ContractBaseInfo)反解;郑商所直接用文件中的交易所 IV(百分数 → 小数)。
- **标准化**:特征 f → 按可得日累积的扩展 z(最少 250 个观测)→ clip ±2 → /2;方向按各节写死;失效:最新可得值超过 10 个日历日 → NaN。
- **执行与评价**:与 `docs/altdata_prereg.md` 第 2 节完全相同(`src/cta/analysis/candidate_eval.py`:standalone / 静态 v0.3 基线 / 50-50 事前风险预算混合;生产执行口径;窗口 2016-01-04 → 2026-06-05;自候选首个持仓日起;OOS 2022-01-04 起;NW 5 阶 + 块 bootstrap 10 × 2000,种子 20261004)。判读 R0–R14 + **R15 家族校正**(3 个候选:混合配对差 bootstrap 区间按 1 − 0.05/3 计算,下限 > 0 才可能是 Candidate)。R0 用信号加权等风险毛收益的 NW t ≥ 2。

## 4. O1(试验 57):期权偏度(看涨相对看跌的溢价)
- **定义**:所选系列中**当日有成交**的期权;看涨取 0.10 ≤ delta ≤ 0.40,看跌取 −0.40 ≤ delta ≤ −0.10(交易所公布的 delta);IV:上期所/能源中心用成交均价(TURNOVER×1e4 / (VOLUME × 合约乘数))反解,郑商所用交易所 IV;skew_T = (成交量加权看涨 IV − 成交量加权看跌 IV)/ 成交量加权看跌 IV(与米筐 `options.get_indicators` 的 skew 同式)。两侧各至少 1 个成交合约,否则当日无值。
- **特征**:f_t = 过去 5 个有值交易日 skew 的均值(至少 3 个)。**方向 +**:看涨相对昂贵 → 做多(Fuertes–Liu–Tang 2022 JFM 商品横截面、Finta–Ornelas 2022 时序 1 个月,均为正号;无中国商品期权证据)。
- **已知弱点**:翼部成交稀少(前月系列常只有 1–3 个成交的虚值合约);上期所成交价与期货结算价不同步;两交易所 IV 方法不同(故只做品种内标准化);文献在 roll yield 之后 alpha 消失(Finta–Ornelas)。

## 5. O2(试验 58):方差风险溢价
- **定义**:σ_A = 所选系列中执行价最接近标的结算价的看涨与看跌的结算价隐含波动率的平均(上期所:Black-76 反解结算价,等于 SIGMA;郑商所:两合约交易所 IV 平均);RV = √(243/21 × Σ 最近 21 个交易日标的连续价对数收益²)(项目复权连续价,≤ T);VRP_T = σ_A² − RV²。
- **特征**:f_t = 过去 5 个有值交易日 VRP 的均值(至少 3 个)。**方向 +**:保险越贵,后续期货收益越高(Kang–Pan 2015 原油、Triantafyllou 等 2015 谷物、Ornelas–Mauad 2019;符号约定为 IV − RV)。
- **已知弱点**:2 周到 3 个月才有证据,日频再平衡可能过快;WTI 与外汇的证据方向相反;中国无商品证据。

## 6. O3(试验 59):去趋势隐含波动率水平
- **定义**:f_t = σ_A(t) / mean(σ_A 过去 243 个交易日中有值的日子,至少 120 个)。**方向 −**:隐含波动率相对自身一年均值偏高 → 做空(Gao 2017,25 个商品月度分组,长低空高 12.7%/年)。
- **已知弱点**:Gao 为工作论文、横截面月度;本轮做日频时序;σ_A 的水平随交易所方法变化(2025-07 大商所口径变化与本轮无关,上期所/郑商所未见口径断点,如实记录)。

## 7. 停止规则
基线不能逐位复现;任一观测的可得日早于 T 之后第一个交易日;所用字段在 T+1 收盘前不可得(例如 2024-03 前上期所文件的首发时刻只能证明 ≤ 20:00,满足 T+1 规则);管道把未成交合约的收盘价当成交价 → 停止并修复。

## 8. 测试(`tests/test_options_signals.py` 与各管道测试)
1. 可得日 = T 之后第一个交易日;2. 系列选择只用 T 当日及以前的信息(持仓、交割月);3. Black-76 反解在合成价格上还原已知 IV;4. 未成交合约不进入 O1;5. 截断到任意 cutoff 重算 ≤ cutoff 的信号不变;6. cutoff 后注入噪声不改历史;7. RV 只用 ≤ T 的价格;8. 2020 年前双边计数不影响比值与成交均价;9. 确定性;10. 失效期。另:全部 pytest、ruff、mypy strict、全量重跑逐字节相同。

## 9. 不改动范围
`configs/strategy*`、champion、五本纸面账、paper/live 执行代码、正式报告主表不动;不据结果调整窗口、方向、delta 区间、系列规则或品种;不纳入大商所(数据缺口);不把 RQData 导出用于重新选择定义。

## 10. 试验计数与预计失败模式(先写)
- 计数 56 → **59**(O1 = 57,O2 = 58,O3 = 59)。
- 共同:期权数据 2019–2020 年才覆盖多数品种,样本内(2021 年前)极短,"样本外"2022 起覆盖最多品种;14 个品种分批上市,AG/RB 只有约 3.5 年、NI/SN 约 2 年;期权 IV 多由同一批做市商报价,信息可能已在期货价格里;T+1 可得规则使日频信号晚一天。
- O1:翼部稀疏 → 噪声大;O2:日频过快;O3:与 O2 共用 σ_A,二者可能高度相关(不合并、各自判读)。
- 任何一条通过,也只能建立未来纸面 challenger;大商所品种需 RQData 导出补齐后另行预注册检验。
