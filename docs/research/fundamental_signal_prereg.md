## 3. 实验 A:Canonical Aggregate Market Interest(试验 50)

### 3.1 论文原定义(Hong & Yogo 2012,NBER WP 16712;细节见文献文档 A1)
美元持仓 = 现货价 × 未平仓合约数(每商品,所有到期月);板块内求和(农产品/能源/畜产品/金属 4 个板块);**每个板块的月增长率 → 四个板块等权平均 → 12 个月几何平均**;月频,x_t 预测 t+1 月;因变量 = 完全抵押商品期货组合的月超额收益(每商品 1–13 个月到期合约等权 → 板块内等权 → 板块间等权);控制短端利率、期限利差、基差、动量、市场失衡、CFNAI;结果 +0.73%/月 每 1 个标准差(t 2.50),符号为正;**没有交易规则**。

### 3.2 中国数据映射(先写死;看结果前不改)
| 项 | 本项目定义 | 与论文的差异及理由 |
|---|---|---|
| 持仓量 | `StitchedSource.contracts(s)` 全部合约逐日持仓量(米筐至 2026-06-05,交易所之后);**2020-01-01 起四所改单边计数,此前 ×0.5 统一为单边**(数据定义修正,`results/…/A_oi_coverage.csv` 记录);任一天全部合约缺持仓量 → 该品种当日 NaN,不补 0 | 中国交易所公布口径;断点由数据事实决定,不是参数 |
| 名义持仓 | N_{i,t} = Σ_合约 持仓量 × 该合约**官方结算价** × 乘数(元);缺结算价回退收盘价并计数(实际 0 行);有持仓无价 → 缺失 | 论文用现货价 × 合约数;中国无全品种现货,用合约自身结算价;含乘数使之为真实名义额(COT 每市场一种合约,论文隐含乘数常数) |
| 板块 | `configs/instruments.yaml` 的 `asset_class`:precious {AG AU}、metal {AL CU NI SN}、ferrous {I J RB}、chem {MA RU SA TA V}、energy {SC}、agri {C CF JD M P SR Y}(设计日志 12.1,事前定义,不按结果改) | 论文 4 个板块;板块数由项目既有映射决定 |
| 月末 | 每个日历月最后一个交易日 T | |
| 板块月增长 | g_{s,t} = log(Σ_{i∈S_{s,t}} N_{i,t} / Σ_{i∈S_{s,t}} N_{i,t−1}),S = 该板块在两个月末都有有限名义持仓的品种(链式,避免上市/缺失跳变) | 论文板块内直接求和;链式是对"品种进入/退出"的最少参数处理 |
| 全市场月增长 | \bar g_t = 有效板块 g_{s,t} 的等权平均;无有效板块 → NaN | 与论文同(板块等权) |
| 预测变量 | x_t = (1/12) Σ_{j=0}^{11} \bar g_{t−j}(对数增长的算术平均 = 12 个月几何平均增长率);任一缺失 → NaN | 与论文同;**不做 3/6/9/18 月** |
| 可得时间 | 月末 T 结算后可得 → 目标暴露记在 T,引擎 T+1 开盘成交 | 论文"滞后一个月" |
| 数据起点 | 持仓量 2016-01-04 起 → \bar g 2016-02 起 → x 2017-01 起 → 24 个月标准化 → **首个可交易信号 2018-12-28**(smoke 输出) | |

### 3.3 主检验(paper-faithful 预测回归)
y_{t+1} = a + b·x_t + e,月频,HAC(Newey–West,3 阶)标准误。y = **固定等风险篮子**(22 个生产品种;权重 w_i ∝ 1/σ_{i,t},σ = 40 日已实现波动,在月末 t 冻结、下月内不变;缺 σ 或缺价的品种当月不参与)从 t 月末收盘到 t+1 月末收盘的对数收益(任务书要求的目标)。**预期 b > 0**(论文)。同时报告(只作对照,不用于判读):论文口径篮子(板块内等权 → 板块间等权)、IS(≤ 2021-12-31)与 OOS(≥ 2022-01-04)子样本、六个板块篮子对同一 x 的回归。

### 3.4 冻结交易映射(唯一版本)
- z_t = (x_t − mean(x_{≤t})) / sd(x_{≤t}),扩展窗口,最少 24 个观测(2 年;与项目内"≥4 年正收益"等规则同量级的最小估计期);s_t = clip(z_t, −2, 2) / 2(与项目现有 ts 信号标准化一致);
- s_t 铺到 22 个品种(篮子外无) → 生产 `vol_target_positions`(w ∝ s/σ、40 日协方差缩放到 10%)→ 总名义 3× 上限 → 暴露缓冲 0.30 → 统一执行引擎(T 收盘定手数、保证金缩减、手数带 0.30、T+1 开盘 ±1 跳、官方结算价盯市、300 万);
- 月内冻结(s 只在月末改变);**不按夏普选阈值、clip、标准化窗口或方向**。
- 为什么不用"x 相对 0":x 是持仓增长,样本均值 +1.5%/月量级,恒为正 → "相对 0"= 恒定做多商品 beta,不是"市场兴趣相对其历史强弱"。

### 3.5 明确不做
不做 OI level / change / z-score 多版本竞赛(合约数口径只记录其与名义口径的相关,不跑);不做逐品种方向;不做窗口扫描;不按板块改映射。

## 4. 实验 B:PMI New-Orders / Finished-Goods-Inventory(试验 51)

### 4.1 假设(固定)
制造业新订单相对产成品库存越强,代表需求相对库存改善,对工业品与能源商品的中期方向偏多。

### 4.2 定义
- ratio_m = 制造业 PMI **新订单指数** / 制造业 PMI **产成品库存指数**(国家统计局,`data/ricecta/data/macro_factors/制造业采购经理指数PMI_新订单.parquet`、`…PMI_产成品库存.parquet`;126 期,2015-12 → 2026-05)。用**比率**而不用差:S&P Global 定义的 orders-to-inventories ratio 即为除法、中性值 1(文献文档 A5);两个分项同量纲(扩散指数);比率与差的相关 0.9993,选择不影响结果。**只跑比率。**
- 禁止替代:产成品库存缺失时不得用原材料库存、购进价格或旧的单品种最佳宏观因子;两分项任一缺失 → 该期不生成信号。
- 可得时间:公布日 D = 米筐 `info_date`(2023-05 之前为回填记录,与统计局惯例一致:2016 年为次月 1 日,2018 年起为当月末日 09:00/09:30;春节等例外按记录;两分项同一公布日);D 当日 09:30 公布晚于日盘 09:00 开盘,故**在 D 之后第一个交易日开盘建仓**,目标暴露记在该交易日的前一个交易日(≤ D);持有到下一次公布;值只从自己的公布日起生效,修订值只从修订公布日起生效(该序列无修订),不回填;超过 45 日无新公布 → 信号失效(NaN,仓位 0);不使用 `rice_create_tm` 之后的修订。
- 数据起点:2016-02-01 首次可用 → 24 个观测 → **首个可交易信号 2017-11-30**(smoke 输出)。

### 4.3 主检验
y = 从本次公布的目标日收盘到下次公布的目标日收盘的**固定等风险篮子**对数收益(篮子见 4.4),x = ratio(含截距,自动居中);HAC 3 阶;**预期 b > 0**。IS/OOS 子样本与农产品篮子(对照)只报告。

### 4.4 篮子(固定)
工业品 + 能源 = metal {CU AL NI SN} + ferrous {RB I J} + chem {MA TA V SA RU} + energy {SC},共 13 个;**不含贵金属**(12.1:金融资产,价格由美元/实际利率驱动,不是制造业需求)与农产品;固定等风险(生产 vol_target 的 w ∝ 1/σ);不因历史表现删除品种;不做"每个品种都必须盈利"的筛选。

### 4.5 交易映射
同 3.4:扩展 z(最少 24 个观测)→ clip ±2 / 2 → 铺到 13 个品种 → 生产风险模型与执行。为什么不用 ratio − 1:样本 92.9% 的月份 ratio > 1(新订单均值 50.6,产成品库存 47.3),"相对 1"几乎恒为做多工业品 beta,不是假设里的"相对强弱";z 的扩展均值不剔除极端值(2020-02 新订单 29.3 会拉大方差),如实记录。

### 4.6 明确不做
不做 z / diff / level / 同比 / 环比多版本;不扫持有期;不按品种挑宏观指标或方向;不加农产品(除非事前经济定义,本轮不加)。

## 6. 判读规则(先写;由脚本机械计算,人只解释)
记号:sa = standalone,bl = 混合,基线 = v0.3;"自首个持仓日起"为默认区间。
- R0 回归:主检验 b 为预期符号(> 0)且 HAC t ≥ 2.0(FULL);
- R1 sa 扣成本月频夏普 > 0;R11 sa 月频 NW t ≥ 2.0;R14 sa 的 IS 与 OOS 净盈亏同号;
- R2 bl 相对基线的配对差点估计 > 0;R3 其 bootstrap 95% 区间下限 > 0;R4 OOS 段配对差点估计 > 0;R12 配对差 ≥ +1.0%/年(实质经济量级);
- R5 sa 与基线日收益相关 ≤ 0.30(不同源);
- R6 最大单季占 sa 正贡献 ≤ 50%;R7 前三品种占正贡献 ≤ 70%;R8 最大单年占正贡献 ≤ 60%;R9 去掉前三品种后完整重跑的月频夏普 > 0;R10 去掉最好一年后月频夏普 > 0;
- R13 点时审计全部通过且基线逐位复现。
判定(每条候选):
- **Invalid**:R13 不成立(前视/时点/字段不可得/基线不能复现);
- **Candidate signal / 值得未来验证**:R0–R14 **全部**成立;
- **Noise / 淘汰**:满足任一——R1 不成立(成本后无净收益)、R2 不成立(混合无增量)、R14 不成立(方向不稳定)、R6 或 R7 不成立(单季或少数品种主导)、(R5 不成立且 R3 不成立:与现有策略同源且无显著增量);
- **Weak evidence / 留档但不采用**:其余情形(点估计为正、经济含义合理,但区间含 0、样本少或集中度过高)。
即便判为 Candidate,也只能建立独立的未来 paper challenger(从结果完成日之后前推),不改生产 champion。
