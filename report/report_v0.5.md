# 中国商品期货 CTA 原型:研究与实盘路径报告(v0.5,2026-10-06)

> **v0.5 相对 v0.4(2026-09-23)的变化**:①新增第 6A 节**非量价因子**——生产中的仓单水平因子说明书,以及把 12 个数据源(11 个非量价 + 全市场持仓)合成一个因子、接入系统的演示(多源基本面合成因子 MSF,配置 v0.6,默认关闭);②第 6 节补入二十至二十五轮研究(试验 47–60:季度重训、全市场持仓、PMI、天气/ENSO/新闻/库存/空气质量、商品期权、合成因子),按各自预注册判读规则无一可采用(样本外配对收益差只有试验 55 上期所库存点估计为正,+0.3%/年、区间含 0;MSF 与 v0.1 混合把样本外夏普从 0.37 提到 0.62,但收益无增量);③基线数字、champion、五本纸面账与 v0.4 完全相同。以下 v0.4 的说明仍然适用。

## 0. 一页摘要

**做了什么。** 一个从数据到出单同一条代码路径的商品期货 CTA 系统:四家交易所直连的日频数据(行情与官方结算价、会员持仓、仓单 2016 年起回填(能源中心 2018 年上市起,其会员持仓排名 2019-11 起才有非空数据;大商所会员持仓排名 2020-07 起);结算/交易参数只接入上期所、能源中心、郑商所(大商所需浏览器,未接入);每日增量、永不覆盖)、合约级回测引擎、事前协方差的波动率目标组合、纸面交易(五本账并行,每日自动运行、事务化落盘、失败告警、git 留痕)。**回测引擎、实盘出单、纸面账本共用 `cta.execution`**:T 收盘价定手数 → 保证金上限缩减 → 手数带 → T+1 开盘按合约级行情成交(缺行情 / 停牌 / 涨跌停预检,换月两腿同进退)→ 按官方结算价盯市。代码质量门:ruff、mypy strict、307 个测试(含引擎级前视测试、纸面账故障注入测试、**2025-03-03 → 04-11 共 29 个真实交易日(首日空仓、其后 28 日有成交)的研究/实盘逐日一致性测试**)、CI。

**策略是什么。** v0.1:时序动量(4 个回看期)+ 展期收益,等权,10% 目标波动,22 个品种,300 万。v0.3(champion):再加交易所仓单水平(设计日志 九–十 按预注册规则从 4 个新数据假设里唯一选入的新因子)。三个 challenger 同在纸面上跑:v0.3p(剔除样本内亏钱的 5 个品种)、v0.1r(交易所上调保证金/手续费后动量减半)、v0.5(v0.3 信号只交易 12 个工业品;事后假设,回测数字只记录)。

**回测怎么样(新基线:统一执行语义 + 官方结算价;完整引擎、含成本、2016-01 → 2026-09;统计自首个持仓日 2017-01-11 起,2016 年为信号预热期、无持仓)。**

**非量价因子(v0.5 新增,第 6A 节)。** 项目里已经有一个在生产中运行的非量价因子:**交易所仓单水平**(注册仓单相对自身一年历史偏低 → 做多)。站在已有量价因子的角度(2017-01-11 → 2026-06-05,与 6A.2 表同窗口,故 v0.1 为 0.88):单独夏普 0.83、与纯量价基线日相关 0.05,50/50 混合把夏普从 0.88 提到 1.09(样本外 0.37 → 0.48),但收益不变(配对差 −0.2%/年,t −0.08),只是回撤更小;按项目判读规则它与 MSF 一样记为"无收益增量",价值只在分散化。这些数字与样本内数字都含选择偏差(这个因子就是在 2017–2021 上按规则选出来的),样本外 +0.11 不显著。另按需求方思路做了**多源基本面合成因子 MSF 演示**:12 个来源等权合成,其中 11 个非量价(仓单、交易所库存、产区降雨、ENSO、新闻语调、钢城空气质量、PMI、期权三项、PPI−PPIRM 剪刀差),另 1 个全市场持仓由持仓量 × 结算价构造、严格说属量价数据;经 `compute_signals` 的可选接口接入系统(配置 v0.6,默认关闭)。来源之间几乎不相关(平均 0.02),在信号层合成后波动降到单个来源的 1/2 到 1/6;但接入引擎后单独夏普 0.54,**弱于仓单单独**(0.83):其余 11 个来源单独平均明显弱于仓单(毛夏普平均约 0.2、样本外约 0.07;只有钢城 PM2.5 的毛夏普 0.76、样本外 0.67 与仓单的 1.18 / 0.68 接近,但它接入引擎后单独只有 0.32、样本外 0.07),等权合成把仓单稀释了。点时检查在 MSF 收益计算之前自动抓到一处前视(周末公布的宏观数据被夜盘提前使用),已修正;同一偏差也存在于 9 月已判 Noise 的 PMI 试验 51(带着有利偏差仍为负,结论不变,未重跑)。

**诚实结论。** (1) 2017–2022 年策略与行业(排排网量化 CTA 趋势指数)同向且不弱(2016 年为信号预热期、无持仓,不参与比较);2023 年起明显落后行业(2025 年行业量化 CTA 均值 +13%,本策略 +3%),主因是展期收益因子 2022 年后失效。(2) 按预注册累计 60 次计数试验,样本内过线 3 个;**按预注册判读规则,样本外没有一个带来可采用的改善**(个别候选样本外点估计为正,如上期所库存混合配对差 +0.3%/年,区间含 0);成本层(成交时点、调仓频率)也没有免费的钱;季度重训(重选附加因子、按滚动夏普给 carry 降权、真正的季度重训模型)不缩小 IS/OOS 差距(十九、二十);免费可得的独立信息与另类数据(全市场持仓、PMI、天气、ENSO、新闻语调、交易所库存、空气质量、商品期权)10 条全部 Noise(二十一至二十三)。(3) 22 个品种继承自朋友仓库,扩到未经挑选的 57 个品种时样本外为负,22 品种的成绩含选择偏差。(4) 无前视:引擎级截断测试依赖不入库的本地真实数据,在本地运行(CI 上自动跳过);研究路径与实盘路径经 2025-03-03 → 04-11 共 29 个真实交易日逐日重放,持仓手数完全相等、权益差 < 1e-6 元;"每个品种正回报"做不到,且按历史盈亏剔品种在样本外是负价值。(5) **执行一致性审计**(2026-09-22,外部复核 + 27 个独立核验)找到并修掉了:纸面按空开盘价"成交"并静默毁账、换月两腿非原子、出单异常被吞、引擎有手数带而出单没有、引擎顺延陈旧目标、盯市口径不同。统一后回测数字几乎不变(v0.3 夏普 1.10 → 1.08),因为对齐的方向是**把手数带加到实盘出单**,而不是从回测里去掉;变的是纸面账从 2026-09-23 起不再为 1 手取整抖动付手续费。(6) 记账口径:改用官方结算价后日波动降约 16%(五个版本 14–17%)、日频夏普 +0.15–0.19(champion v0.3 +0.19),但**月频夏普基本不变**(本报告一律用月频);v0.3 报告里"纸面夏普口径会高 18%"的说法只对日频成立,已更正。(7) 板块诊断(农产品亏在慢动量与展期收益,快动量样本外为正;贵金属相反)只登记为候选,不改动。

**现在在跑什么。** 五本纸面账的账期都从 2026-09-16 起算(v0.1 于北京时间 09-17 开立,v0.3 于 09-19、其余三本于 09-22 开立,开立前的交易日用点时数据补算),此后每个工作日多伦多 05:10(北京 17:10;2026-11-01 多伦多结束夏令时后为北京 18:10)自动拉数、成交、盯市、出单;2026-09-23 起订单为统一口径。**规则(预注册,`docs/design_log.md` 十八):v0.3 为 champion,其余为 challenger;三个月(至 2026-12-15)只做工程验收(数据完整率、成交率、滑点校准、对账、故障恢复演练);只报告各 challenger 相对 champion 的配对 PnL 差及其区间,不选赢家;版本采用决定不早于 2027-09**(3 个月夏普差的标准误 ±1.29,12 个月才降到 ±0.65)。

## 1. 任务与约束

- 起点(2026-09-03):守正用奇的题目"完成一个多因子策略,品种任选"。9-09 需求方明确:公司已有两个中证 1000 指增产品,建议做 CTA;定位是"进公司后 8 个月内上线的个人原型,代码质量是首要标准";评审看收益与夏普,更看有没有过拟合、前视、无法上线的问题。
- 约束:只用免费数据(米筐历史导出 + 交易所官网公开数据);资金 100–500 万(默认取中点 300 万);任何看过结果后的改动进设计日志并计试验数。
- 需求方后续要求逐条落实:参数按交易所核验(9-11)、与私募排排网产品对照(9-11)、挖掘因子(9-12)、接近实盘(9-14)、去 alphaXiv 找因子(9-16)、给品种分类每组三因子加权(9-21)、每品种正回报 + 无前视(9-22)、挖新数据(9-22)、"农产品差是不是动量太快"(9-22,已诊断)、暂不接 CTP、评价指标为夏普/最大回撤/样本外年化(9-22)。
- 2026-09-22 外部复核提出 5 条研究/实盘不一致,经核验 4 条成立、1 条方向相反;需求方拍板:先补事务缺口,再做路径统一、官方结算价基线、纸面规则重置,三步一起做、只重出一次报告(本版)。

## 2. 系统

```
交易所官网(SHFE/INE/CZCE/DCE) ──每日──▶ data/exchanges/<所>/{quotes,params,positions,receipts}/<日>.parquet(点时,永不覆盖)
米筐导出(2016 → 2026-06-05) ─────────▶ StitchedSource(米筐历史 + 交易所增量;米筐段的结算价用交易所官方值逐合约覆盖)
                                          │
                              build_panels:主力判定(T−1 持仓量最大 + 3 日确认 + 只向更晚到期切换)、T+1 排程合约、回溯复权、官方结算价(缺失即报错)
                                          │
                              compute_signals:tsmom / carry / receipts_level(可选)/ 外部因子 msf(可选,v0.6 演示)/ 监管覆盖(可选)→ 等权 → 协方差缩放到 10% → 上限 → 暴露缓冲
                                          │
                              cta.execution.plan_lots(唯一的手数规划):T 收盘价 × T+1 合约 → 整手 → 保证金上限缩减 → 手数带 → 绝对目标手数
                                          │
                 ┌────────────────────────┴─────────────────────────┐
        run_backtest(研究)                                   generate_orders(实盘/纸面,as-of = T)
        面板排程驱动同一账本                                   同一函数,输出 orders.csv + 输入快照 + 指纹
                 └────────────────────────┬─────────────────────────┘
                              cta.execution.ledger(唯一的成交/盯市状态机):每腿预检(缺行情 / 空开盘价 / 涨跌停)→ 换月两腿同进退
                              → 开盘价 ± 1 跳成交、手续费按成交价 → 按持仓合约自身的官方结算价盯市 → 有限值断言
                                          │
                              paper/runner(纸面):全部产物先写 .txn/<日>/,成交、盯市、出单都成功才替换正式文件、state.json 最后;
                              失败 → FAILED.json + 非零退出 + 桌面通知,状态不变,重跑幂等;git 留痕
```

- 合约参数:57 个品种的乘数、跳价、保证金、涨跌停、手续费全部按交易所官网一手来源核验(两名独立复核),带生效日与来源 URL(`configs/instruments.yaml`,`docs/data/instruments_verification*.md`)。生产品种池由配置显式列出 22 个。
- 结果目录以"配置指纹 + 参数表指纹"命名;每次出单的快照含 git sha、数据指纹、配置指纹、结算价口径与覆盖率。
- 质量门:`ruff format/check`、`mypy --strict`、`pytest`(307 项:合成数据单元测试 + 真实数据的三层截断不变测试 + 交易所解析样例 + 纸面账故障注入 + **研究/实盘逐日一致性** + 另类数据管道与合成因子的点时测试)、GitHub Actions。旧引擎冻结为 `engine_legacy.py`,只用于复现 v0.3 报告。

## 4. 策略定义(v0.1 → v0.3,及三个对照版本)

- **时序动量**:回溯复权主力连续价,过去 21/63/126/252 日收益各自除以波动率并截断,四个回看期等权平均。
- **展期收益**:(主力 − 次主力)/次主力 按两合约到期间隔年化,tanh 压缩到 [−1, 1]。
- **仓单水平**(v0.3):log(1+注册仓单) 在自身 252 日窗口内的分位,取负后做横截面 z-score。
- **合成**:等权平均,缺失因子不进分母,按活跃因子数 √(n/n_max) 归一。不拟合权重。
- **仓位**:名义暴露 ∝ 合成信号 / 波动率;40 日协方差把组合事前波动缩放到年化 10%;单品种 ≤1 倍权益、总名义 ≤3 倍;暴露缓冲 0.30(`exposure_buffer`,信号层)。
- **执行(统一语义,引擎 = 出单 = 账本)**:T 收盘后,用 T+1 将持有的合约(排程由 ≤T 的持仓量决定)在 T 的收盘价把暴露换成整手 → 预计保证金 > 40% 权益时全体等比缩减 → 手数带 0.30(`lot_band`:|目标 − 持仓| < 0.3 × max(1, |持仓|) 不交易,清仓除外)→ 绝对目标手数。T+1 开盘每腿预检(缺行情 / 开盘价为空 / 触及涨跌停则当日不成交,次日按最新信号重算,不顺延陈旧目标);换月先平旧再开到目标,两腿任一不可成交则两腿都不动;成交价 = 开盘价 ± 1 跳,手续费按成交价与核验表;每日按持仓合约自身的官方结算价盯市。
- **多源基本面合成因子 MSF**(v0.6 演示,`configs/strategy_v06_msf.yaml`,默认关闭、不进纸面):12 个成分,其中 11 个非量价(仓单、上期所库存、产区降雨、ENSO、新闻语调、钢城 PM2.5、PMI 订单/库存、期权偏度/方差风险溢价/去趋势 IV、PPI−PPIRM 剪刀差),另加全市场持仓(持仓量 × 结算价 × 乘数,属量价数据);各按自己预注册的定义与可得时间算出 [−1, 1] 信号,等权合成、按有值成分数 √(n/12) 归一;v0.6 = 时序动量 + 展期收益 + MSF(MSF 取代单一仓单因子),其余参数与 v0.3 相同。见 6A.2。
- **监管覆盖**(v0.1r)、**剔品种**(v0.3p:去掉 AG、AU、M、SA、SR)、**工业品池**(v0.5:只留 CU AL NI SN AU AG SC MA TA V SA RU)定义同 v0.3 报告。

## 6A. 非量价因子(v0.5 新增)

需求方(2026-10-05):"我们比较缺的是商品期货的非量价因子,量价因子可以复用。"本节回答两件事:项目里已经在跑的非量价因子是什么、表现如何;把十几个非量价数据源合成一个因子、接进系统是什么样子。

### 6A.1 已在生产中的非量价因子:交易所仓单水平(`docs/research/non_pv_factor_card.md`)
- **数据与定义**:四所每日《仓单日报》的注册仓单(可交割的仓库库存),不用价格与成交量;x = log(1 + 仓单),取自身过去 252 日分位,仓单相对一年历史偏低 → 做多;横截面 z。机制是库存理论(低库存 → 现货紧、持有者要求更高溢价;Gorton–Hayashi–Rouwenhorst 2013),国内研报方向一致。
- **相对纯量价基线 v0.1**(完整引擎、300 万、官方结算价、含成本):自首个持仓日(2017-01-11)起至 2026-06-05 单独月频夏普 0.83(样本内 1.27、样本外 0.29;与 6A.2 表同窗口,v0.1 在此窗口为 0.88),与 v0.1 日相关 0.05;50/50 风险预算混合 0.88 → **1.09**(样本外 0.37 → 0.48),收益不变(配对差 −0.2%/年,t −0.08;样本外 −0.4%/年,t −0.10)、回撤更小——价值在分散化;按本项目判读规则(要求混合后收益差 > 0)记为"无收益增量",与 MSF 相对 v0.1 同类。样本内与自首个持仓日起的数字都含选择偏差(因子是在样本内按规则选出的),样本外 +0.11 不显著。22 个品种 16 个全区间为正(50/50 混合臂为 17 个),去掉前三仍 0.47;2024 年亏损(国泰君安实盘"截面仓单"指数同年也亏)。
- **时点**:代码对齐无前视(T 日仓单 → T 日信号 → T+1 开盘成交,有夜盘品种即 T 日 21:00)。有真实时间戳的样本里仓单都在 21:00 前公布(上期所/能源中心 2024-03 起、郑商所 2025-07 起,四所 2026-08/09 全部核对);但 2016–2024 年的首发时刻无法证明,交易所还事后重写过 15 个文件。17:10 的纸面跑约 2–3% 天数早于公布(当日用前一天的仓单),改进需调整运行时刻,已登记待拍板。

### 6A.2 多源基本面合成因子 MSF(演示;试验 60;`docs/research/msf_prereg.md`、`docs/research/msf_demo.md`)
- **做法**:12 个来源(11 个非量价;全市场持仓由持仓量 × 结算价构造,属量价数据),每个按自己事先写定的定义、方向与可得时间算出 [−1, 1] 的信号;每天每个品种取有值来源的等权平均,再乘 √(有值来源数 / 12)(来源少时信号自动变小),不按收益给权重、不挑来源。新增来源 P = PPI 同比 − PPIRM 同比的 3 个月变化,去极值;由需求方的建议简化而来(原话是"PPI 和工业 PPI 原材料指数与 GDP 平减差值的变化率 winsorize",反映工业企业采购原材料的能力)。PPI 与 PPIRM 之差本身就度量工业企业卖出价相对买入价;GDP 平减指数是季度数据、滞后约 6 周,未纳入。
- **接入**:`src/cta/factors/composite.py` 构造;`compute_signals(extra_factors=…)` 只在配置权重写了 `msf` 时使用,研究回测与每日出单走同一函数;演示配置 `configs/strategy_v06_msf.yaml`(时序动量 + 展期收益 + MSF)。现有配置的权重都不含 `msf`,这个入口对它们不起作用;champion v0.3 由测试核对(传入 msf 时输出逐位不变,需本地数据);纸面账不用。
- **点时**:每个来源有审计表;5 个截断日(含周末公布前的周五、春节前月末)重算不变;**第一次运行在收益计算之前被截断检查自动停下**——统计局周末公布的 PMI/PPI 被记到前一个周五,夜盘会在公布前成交;修正为"公布日当天或之后第一个交易日"后通过(同时修正节前月末判定)。

- v0.6 一行与表中其余各行同一窗口(由 `results/msf_demo/equity_v06_msf.csv` 自 2017-01-11 起计算);`docs/research/msf_demo.md` 第 3 节的系统级数字从 2016-01-04 起算、含 2016 年空仓预热期(v0.6 0.85 / v0.3 1.00 / v0.1 0.84),两种窗口下 v0.6 都与 v0.1 持平或略高、低于 v0.3。
- **读法**:12 个来源两两相关平均 0.02,合成后(评估器口径,信号未按目标波动缩放)波动只有单个来源的 1/2 到 1/6,毛夏普 0.70 高于成分平均约 0.3——分散化确实发生;但除仓单外的 11 个来源单独平均明显弱于仓单(毛夏普平均约 0.2、样本外约 0.07;唯一接近的是钢城 PM2.5,毛 0.76 / 样本外 0.67,对仓单 1.18 / 0.68),等权合成把仓单稀释了,所以 MSF 单独(毛 0.70 / 净 0.54)弱于仓单单独(毛 1.18 / 净 0.83);按目标波动运行后 MSF 单独回撤 −22.2%,并不比单一因子低风险。相对纯量价 v0.1,混合后收益不变、夏普 0.88 → 1.02,和仓单因子的结论同类(价值在分散化);相对已经含仓单的 v0.3 则拖低(配对差 −3.3%/年,t −1.3)。v0.6 与 v0.1 日相关 0.96:MSF 信号平均幅度只有 0.12,在系统里分量很小。按判读规则两种基线下都是 Noise;12 个来源中除需求方新建议的 P 外,其余 11 个在 2016–2026 上都已单独检验过(仓单:设计日志九、十;其余 10 个:试验 50–59),合成的收益又主要来自其中的仓单,**这些数字只是演示,不是证据**。
- **结论**:多源组合 + 插入系统的框架已经可用,新数据源写成一个成分即可接入,点时检查自动覆盖;要让组合强于单一因子,需要更多本身有效的来源(付费产业链库存/开工率、带时间戳的新闻全文),不是更多数量。本因子不是"世界模型",是多信号等权合成。

## 9. 结论

1. **可上线的骨架,且研究与实盘走同一条路**:数据、引擎、风控、出单、账本、留痕、测试、CI 齐备;执行层的每一条规则只有一份实现,并经真实数据逐日重放验收。
2. **信号弱且集中**:两个教科书信号加一个仓单因子,全样本夏普 0.87–1.08,2022 年后 0.35 左右;收益最集中在有色与贵金属(v0.3 全样本净盈亏的约 46%;样本外两者合计 +196 万,超过样本外全部净盈亏 +165 万);全样本六个板块均为正,样本外农产品与黑色为负(合计 −81 万)。
3. **已检验的公开数据没有增量,成本层与重训频率也走完**:60 次计数试验,按预注册规则样本外没有一个带来可采用的改善;季度重选因子、按滚动夏普给 carry 降权、真正的季度重训模型都不缩小 IS/OOS 差距;免费独立信息、另类数据(天气/新闻/库存/空气质量)与商品期权 10 条全部 Noise;成交方式在样本内 ±0.05 夏普以内、样本外替代方式全部差 0.10–0.17,降低调仓频率使样本内夏普降 0.07–0.08,都不采用。
4. **非量价因子**:仓单水平是唯一按规则(设计日志九、十,样本内)选入的非量价因子,价值只在分散化(相对纯量价:收益不变、夏普 0.88 → 1.09,自 2017-01-11 起窗口;按判读规则与 MSF 同为"无收益增量",样本内含选择偏差,样本外 +0.11 不显著);多源合成因子 MSF 已作为演示接入(默认关闭),框架与点时检查可复用,但在免费数据上合成弱于仓单单独——组合要变强,需要更多本身有效的数据源(付费产业链、带时间戳的新闻全文),不是更多数量。
5. **口径修正不改变结论**:执行统一与官方结算价把 v0.3 全样本夏普从 1.10 改到 1.08、回撤从 −14.0% 改到 −14.4%;所有版本间的相对结论不变。旧数字保留并解释。
6. **对"每品种正回报"的回答**:样本内可构造,样本外做不到,且做法本身有害;板块层面有结构,但据此选池是事后假设,只能前向检验。
7. **下一批证据来自五本纸面账的工程验收(2026-12-16)与配对差报告**;不选赢家,不再改信号。
